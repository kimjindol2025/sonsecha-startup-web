## 발견 사항

### CR-1 · 전달 IP 헤더로 요청 제한을 우회할 수 있음

- 심각도: 보통
- 위치: `server.mjs`의 `requestAddress()`
- 문제: `X-Forwarded-For`의 첫 값을 바로 IP로 사용한다. 호출자가 이 헤더를 선택할 수 있는 구성에서는 관리자 로그인, 의견 제출, 분석 이벤트의 IP별 제한을 다른 IP를 지정해 회피할 수 있다.
- 조치: 소켓 상대 주소가 명시적으로 신뢰된 프록시 목록에 있을 때만 전달 체인을 사용한다. 프록시 주소 목록은 `TRUSTED_PROXY_IPS`로 설정한다.
- 상태: 코드 수정 완료. 최초 배포 때는 서버 73 Nginx를 프록시로 확인해 `TRUSTED_PROXY_IPS=192.168.45.73`을 지정했으나, 2026-11-06 22:02 KST 라우팅 확인에서 실제 진입점은 server23으로 밝혀졌다. server23 direct map은 `sonsecha.dclub.kr`을 `192.168.45.25:40330`으로 보낸다. 22:14 KST server25의 `sonsecha-startup-web`만 재시작하고 신뢰 프록시 주소를 `192.168.45.23`으로 수정했다.

### CR-2 · 월 운영 예시가 기존 입력을 덮어씀

- 심각도: 보통
- 위치: `src/business-plan.js`의 `fill-sales-example` 처리
- 문제: 예시 버튼이 객단가·차량 수·영업일과 8개 운영비를 확인 없이 교체한다. 창업예산 예시 버튼과 달리 기존 입력을 보호하는 확인 절차가 없다.
- 조치: 기존 값이 있으면 덮어쓰기 전에 확인한다.
- 상태: 수정 완료. 예산·매출 예시 모두 기존 값이 있으면 교체 확인을 표시한다.

### CR-3 · 복사 문서에서 후보지 메모와 공식 자료가 빠짐

- 심각도: 보통
- 위치: `src/business-plan.js`의 `fullPlanText()`
- 문제: 화면의 인쇄 문서에는 후보지 세부 메모와 공식 자료 경로가 포함되지만, `내용 복사` 결과에는 빠져 있다.
- 조치: 후보지 판정·세부 메모와 공식 자료 이름·링크를 복사 결과에 포함한다.
- 상태: 수정 완료. 복사 결과에 후보지 판정·세부 메모와 공식 자료 링크를 포함한다.

### CR-4 · 브라우저 저장 실패를 처리하지 않음

- 심각도: 낮음
- 위치: `src/business-plan.js`의 `save()`
- 문제: `localStorage.setItem()`이 저장 공간 부족이나 브라우저 설정으로 실패하면 예외가 발생하고 저장 상태 메시지도 갱신되지 않는다. 화면 입력은 바뀌어 보여도 새로고침하면 사라질 수 있다.
- 조치: 실패를 잡아 사용자에게 저장되지 않았음을 표시한다.
- 상태: 수정 완료. 브라우저 저장이 실패하면 저장 실패 안내를 표시한다.
