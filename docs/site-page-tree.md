# 손세차장 창업 로드맵 페이지 트리

현재 사이트의 고객용 공개 페이지, 관리자 영역, 보조 페이지와 주요 API 구조를 정리한 문서입니다.

│  ├─ #roadmap 창업 절차 12단계
│  │  ├─ 후보지 사전 확인
│  │  ├─ 건축사 용도변경 검토
│  │  ├─ 조건부 임대차계약
│  │  ├─ 폐수처리계획 설계

## 2. 관리자 영역

```text
관리자
├─ /admin/login
│  └─ 관리자 로그인
└─ /admin
   ├─ 메인 글 관리
   ├─ 상품 관리
   ├─ 상품 이미지 업로드
   ├─ 클릭 분석
   ├─ 후보지 검토 요청 관리
   └─ 사용자 피드백 관리
```

`/admin` 페이지와 `/api/admin/*` API는 관리자 인증이 필요한 보호 영역입니다. 관리자 링크는 고객용 공개 메뉴에 노출하지 않습니다.

## 3. 보조 페이지

```text
/workspace.html
└─ 창업 진행판 체험·준비 중 기능
```

## 4. 주요 API

```text
/api
├─ GET  /products
├─ GET  /content
├─ POST /feedback
├─ POST /consultations
├─ POST /analytics/click
├─ POST /ai/products
└─ /admin
   ├─ 로그인·세션
   ├─ 상품·이미지 관리
   ├─ 콘텐츠 관리
   ├─ 분석 조회
   ├─ 피드백 관리
   └─ 후보지 상담 관리
```

## 5. 경계와 운영 원칙

- 고객용 페이지는 창업 절차, 후보지 검토, 허가 확인, 사업계획서, 제품·상담 정보를 제공합니다.
- `/permit`의 결과는 법률 자문이나 허가 완료 판정이 아니며, 최종 확인은 소재지 관할 기관과 전문가에게 요청합니다.
- `/construction-prep`는 현재 공개 구현되지 않았으므로 고객용 트리에 포함하지 않습니다.
- 관리자 상품·콘텐츠 기능과 고객용 상담·이메일 기능은 인증 및 API 경계를 유지합니다.
