## 사용자 요청을 해석한 방식

사용자는 고객 반응을 먼저 확인하자는 영상을 공유한 뒤 “피드백 받게 게시판 우리서버 db”를 요청했다. 이를 외부 폼·분석 서비스가 아니라 현재 손세차장 창업 가이드 서버가 직접 의견을 받고, 자체 DB에 보관하며, 기존 비밀번호 관리자에서 처리하는 기능으로 해석했다.

“게시판”은 방문자 의견을 그대로 공개하는 공개 커뮤니티가 아니라 운영자용 피드백 수신함으로 구현했다. 검수되지 않은 글에는 개인정보·광고·악성 내용이 들어갈 수 있으므로 공개 노출보다 관리자 전용 열람을 기본값으로 선택했다.

## 변경 내용

### 우리 서버 SQLite DB

- Node 22 내장 `node:sqlite`의 `DatabaseSync`를 사용해 외부 DB 서비스와 새 패키지 없이 `data/feedback.sqlite`를 생성한다.
- `feedback` 테이블에 의견 종류, 관련 화면, 본문, 페이지, 기기 구분, 처리 상태, 생성·수정 시각을 저장한다.
- 이름, 전화번호, 이메일과 IP 주소는 컬럼 자체를 만들지 않았다.
- DB 파일 권한은 `0600`으로 설정하고 기존 `data/` 제외 규칙으로 Git에 포함하지 않는다.
- 공개 `POST /api/feedback`, 관리자 `GET /api/admin/feedback`, 상태 변경 `PATCH /api/admin/feedback/:id`를 추가했다.
- 공개 작성은 접속 주소별 시간당 5개로 메모리에서 제한하고, 숨은 웹사이트 필드로 단순 자동 스팸을 저장 전에 걸러낸다.
- 목록은 최신 500개로 제한하며 상태는 `new`, `reviewing`, `done`만 허용한다.

### 방문자 작성창

- 모든 화면에서 접근 가능한 `의견 보내기` 고정 버튼을 추가했다.
- 의견 종류는 도움됐어요, 불편해요, 기능 제안, 기타 의견이다.
- 현재 화면 위치를 기준으로 창업가이드, 12단계 절차, 후보지·실무 체크, 제품몰, 장바구니·견적서를 자동 추천한다.
- 본문은 5~1,000자로 제한하며 저장 중·성공·오류 상태를 화면에서 안내한다.
- 이름·연락처·IP를 저장하지 않는다는 설명과 답변이 필요한 경우 상담전화를 사용하라는 안내를 넣었다.
- 520px 이하에서는 선택지가 2열, 전송 버튼이 전체 너비가 되며 모달 최대 높이는 모바일 화면 안으로 제한된다.

### 관리자 피드백 게시판

- 기존 관리자 탭에 `사용자 피드백`을 네 번째 관리 항목으로 추가했다.
- 새 의견, 검토 중, 완료, 전체 건수를 요약한다.
- 본문·관련 화면 검색과 상태 필터, 새로고침을 제공한다.
- 각 의견은 종류, 상태, 작성 시각, 내용, 관련 화면, 기기, 페이지를 표시한다.
- 관리자 버튼으로 처리 상태를 즉시 변경하고 DB에 반영한다.
- 모바일에서는 통계가 2열이 되고 상태 버튼은 3열 전체 너비로 배치된다.

## 실수와 교정

- 처음에는 “게시판”을 공개 목록으로도 해석할 수 있었지만, 검수 전 의견을 모두 공개하면 개인정보와 스팸이 노출될 수 있다. 현재 단계에서는 관리자 전용 수신함이 고객 반응 수집 목적에 더 안전하다고 판단했다.
- JSON 파일도 구현 가능했지만 사용자가 명시적으로 서버 DB를 요청했다. 프로젝트에 외부 DB 의존성이 없는 점을 확인하고 Node 내장 SQLite를 선택했다.
- 고객 반응 수집이 목적이므로 답변을 위한 이름·연락처 필드를 추가하지 않았다. 직접 상담이 필요한 사용자는 기존 하단 전화번호로 분리한다.
- 개발 편의를 위해 운영 DB에 테스트 글을 넣지 않았다. 모든 쓰기·상태 변경 검증은 별도 임시 데이터 디렉터리에서 수행했다.

## 남은 위험과 다음 작업

- `node:sqlite`는 현재 Node 22에서 실험 기능 경고를 출력한다. 운영 Node 버전 변경 시 API 호환성을 다시 확인해야 한다.
- `data/feedback.sqlite`는 Git 제외 운영 데이터이므로 기존 상품·콘텐츠·분석 파일과 함께 백업 대상에 포함해야 한다.
- 현재 관리자는 최근 500개를 한 번에 읽는다. 피드백이 많아지면 서버 페이지네이션과 기간 필터가 필요하다.
- 공개 답글, 관리자 메모, CSV 내보내기, 첨부파일, 알림은 아직 범위 밖이다.
