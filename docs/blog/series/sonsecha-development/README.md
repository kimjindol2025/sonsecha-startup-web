## 이 기록을 남기는 이유

이 프로젝트는 처음부터 완성된 기획서대로 만들어지지 않았다. 사용자가 운영 화면을 직접 확인하고 “모바일에서 안 보인다”, “주소별로 따로 체크해야 한다”, “상품이 처음부터 나오면 안 된다”, “내 회사 정보가 없다”, “클릭 반응을 보고 싶다”고 교정할 때마다 구조가 바뀌었다.

따라서 최종 코드만 보면 왜 현재 구조가 되었는지 알기 어렵다. 이 연재는 무엇을 만들었는지만이 아니라, 잘못 해석한 지점과 사용자가 바로잡은 기준까지 기록한다. 다음 Codex나 Cursor는 이 기록을 먼저 읽고 같은 실수를 반복하지 않아야 한다.

## 현재 운영 원칙

- 모바일 화면을 완료 기준의 중심에 둔다.
- 허가 가능 여부를 온라인 정보만으로 단정하지 않는다.
- 후보지별 데이터는 서로 섞이지 않게 분리한다.
- 운영 비밀번호와 서버 데이터는 Git에 기록하지 않는다.
- 무료 사용자의 실제 반응을 먼저 확인한다.
- 이름·연락처·IP처럼 필요하지 않은 개인정보는 수집하지 않는다.
- 기능을 추가할 때 빌드, API, 모바일 UI와 운영 HTTPS를 함께 검증한다.
