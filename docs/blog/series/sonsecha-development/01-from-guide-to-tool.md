## 출발점

프로젝트의 첫 형태는 손세차장 창업 절차를 한 화면에 정리한 정적 웹페이지였다. 입지 확인, 건축물 용도변경, 폐수배출시설 신고, 시설공사, 사업자등록과 개업까지 12단계로 나누고, 계약이나 공사보다 행정 가능 여부를 먼저 확인하라는 메시지를 중심에 두었다.

초기 커밋 `632644a`는 페이지 골격을 만들었고, `76ba8e1`은 Sites 런타임에 배포할 수 있도록 정적 자산 패키징을 추가했다. `d6c4528`, `65eaedb`, `20aec07`에서는 README와 화면 본문을 확장해 단순 홍보물이 아니라 창업 순서를 설명하는 가이드로 만들었다.

## 읽는 페이지에서 쓰는 페이지로

안내문만으로는 실제 후보지를 검토할 때 진행 상태를 남길 수 없었다. 그래서 각 단계에 상세 항목을 열고 체크할 수 있게 했으며, 브라우저를 닫았다가 다시 열어도 상태가 남도록 `localStorage`를 사용했다.

- `c994be3`: 단계별 상세 체크리스트 영속 저장
- `67e4d19`: 상세 메모와 후보지 주소 저장
- 각 단계 완료 여부와 전체 진행률 표시
- 확인한 부서, 담당자, 회신 내용과 근거를 적는 메모

서버 계정이 없어도 자신의 브라우저에서 바로 사용할 수 있다는 점은 무료 도구의 장점이었다. 동시에 데이터가 다른 기기와 공유되지 않고 브라우저 삭제 시 사라질 수 있다는 한계도 생겼다.

## 이 단계에서 배운 것

첫 번째 변화의 핵심은 정보량이 아니었다. 사용자가 해야 할 행동을 기록할 수 있을 때 비로소 안내 페이지가 도구가 되었다.

하지만 아직 저장 단위는 후보지 한 곳뿐이었다. 여러 주소를 비교하면 체크와 메모가 섞이는 구조였고, 모바일 화면도 데스크톱 레이아웃을 줄인 수준이었다. 다음 단계에서는 이 두 문제가 사용자 교정으로 드러났다.
