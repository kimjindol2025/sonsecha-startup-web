# 상품몰 등록 안내

상품 데이터는 `src/products.js`에서 관리한다. 현재 공개 상품은 없으며 쇼핑몰 화면은 빈 상품 상태로 운영된다.

## 상품 등록 형식

```js
{
  id: '고유-상품코드',
  name: '상품명',
  category: 'chemical',
  summary: '목록에 표시할 짧은 설명',
  price: 25000,
  image: '/products/상품이미지.webp',
  shopUrl: 'https://k002.com/mall/m_mall_detail.php?ps_goid=상품번호',
  badge: 'BEST',
  inStock: true,
  featured: 10,
}
```

- 카테고리 값은 `chemical`, `tool`, `equipment`, `safety` 중 하나를 사용한다.
- 가격을 정하지 않은 상품은 `price: null`로 등록하면 `가격 문의`로 표시된다.
- 품절 상품은 `inStock: false`, 임시 비공개 상품은 `active: false`로 설정한다.
- `featured` 숫자가 클수록 추천순에서 먼저 표시된다.
- 상품 이미지는 가급적 같은 비율의 WebP 파일로 준비하고 `public/products/`에 둔다.
- 기존 `k002.com` 상품은 `shopUrl`에 상세페이지 주소를 넣어 `공식몰 상세` 버튼으로 연결한다.

## k002.com 샘플 상품

2026-07-31 KST 기준 `k002.com` 메인에 공개된 상품 8개를 샘플로 등록했다. 상품명·가격·이미지와 상세페이지는 기존 공식몰의 공개 정보를 기준으로 한다. 기존 쇼핑몰에서 가격·판매상태가 바뀌어도 이 정적 데이터에는 자동 반영되지 않으므로 정식 운영 전 반드시 대조해야 한다.

## 현재 주문 흐름

상품 선택 → 장바구니 수량 조정 → 간이견적서 작성 → 인쇄·PDF 저장 또는 전화 주문·견적 문의 순서다. 장바구니와 견적 받는 분의 입력 내용은 이용자의 브라우저에 저장된다.

간이견적서에는 상품명·단가·수량·합계와 공급자 정보가 자동으로 들어간다. 회사·상호, 담당자, 연락처, 이메일, 배송·설치 주소와 요청사항은 이용자가 직접 입력한다. 가격 문의 상품과 배송비·설치비·부가세 적용은 최종 상담에서 확정해야 한다.

온라인 결제, 서버 주문 저장, 재고 차감, 배송조회는 아직 연결하지 않았다. 해당 기능은 PG 계약, 주문 API, 관리자 인증과 개인정보 처리 설계가 확정된 뒤 추가해야 한다.
