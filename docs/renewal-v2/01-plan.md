## 1. 사업 정의와 개편 목표

빅워시는 세차장 토목·건축, 세차장 장비 제조, 장비 설치와 오픈까지 진행하는 회사다. 셀프세차·손세차 창업자가 전체 공정을 맡기거나 필요한 공정·장비만 의뢰할 수 있도록 사업 범위를 보여준다.

사이트 이름은 “빅워시 세차장 창업”으로 통합한다. 메인에서는 빅워시의 전체 수행 범위를 먼저 전달하고, 창업 안내·사업계획·후보지 기록·제품몰을 상담을 돕는 도구로 배치한다.

고객의 핵심 동선은 “세차 방식 선택 → 시공·장비 구성 확인 → 실제 사례 확인 → 필요한 범위 상담”이다. 후보지가 없는 예비 창업자와 기존 세차장의 장비 교체 고객도 상담할 수 있게 한다.

## 2. 확정된 사업 범위와 자료 사용

| 구분 | 기획에 반영할 내용 | 표현 기준 |
|---|---|---|
| 사업주 확인 | 토목·건축·세차장 장비 제조·설치·오픈 진행 | 빅워시의 정식 사업 범위로 반영 |
| 공식 제품몰 | 고압세척기·폐수처리기·셀프세차 장비·부품·소모품 | 실제 취급 제품과 연결 |
| 제품별 제조 | BW2015 직접 제조·조립 공개 안내 | 제조 설명은 해당 품목의 사실에 맞춰 작성 |
| 과거 외부 활동 | 2018년 창업·경영 세미나, 2022년 전문지 필진 소개 | 연도를 표시한 이력으로 활용 |
| 시공 실적 | 개별 현장·수행 공정·사진·시기 | 확보된 실제 자료로 사례 구성 |

사업주가 확인한 사업 범위를 외부 검색 결과가 적다는 이유로 축소하지 않는다. 개별 실적 수·등록 면허·인증·제조 품목·보증 조건은 해당 자료에 근거해 구체화한다. 외부 지도에서 이름이 같은 매장을 발견해도 빅워시 시공 사례로 자동 등록하지 않는다.

대표 문구:
“세차장 창업, 토목부터 오픈까지.”

소개 문구:
“셀프세차·손세차장의 토목·건축부터 세차장 장비 제조·설치와 오픈 준비까지, 빅워시가 현장에 맞춰 진행합니다.”

주요 행동: “셀프세차 창업 보기”, “손세차 창업 보기”
상시 상담 버튼: “창업·시공 상담”

제품 판매 외에 전체 창업 공정과 제조·설치 역량이 드러나게 한다. 전체 진행과 부분 의뢰를 함께 안내한다.

## 4. 세 가지 분야의 역할

| 분야 | 페이지 성격 | 고객에게 제공할 내용 |
|---|---|---|
| 셀프세차 | 빅워시 창업·시공 서비스 | 베이·드라잉존·동선·토목·건축·장비·설치·오픈 |
| 손세차 | 빅워시 창업·시설 서비스 | 작업 공간·차량 대기·급배수·폐수·장비·설치·오픈 |
| 노터치 자동세차 | 기존 시장 리서치 | 기존 한국 노터치 자동세차 리서치 보고서 유지 |

노터치 보고서는 기존 제목·본문·출처·기준일을 유지하고 상단 공통 메뉴를 제공한다. 셀프·손세차는 빅워시 서비스와 의뢰 동선으로 연결한다. 복합형 문의는 상담에서 함께 받는다. 노터치 리서치가 노터치 장비 제조·시공 제공을 의미하도록 표현하지 않는다.

## 5. 메뉴와 공통 화면

로고 클릭은 항상 새 메인으로 이동한다. 모든 상세 페이지에 동일한 주요 메뉴와 홈 이동 수단을 둔다.

| 주요 메뉴 | 내용 |
|---|---|
| 셀프세차 창업 | 방식·공간·공정·장비·상담 |
| 손세차 창업 | 공간·작업 동선·공정·장비·상담 |
| 토목·건축 | 부지와 시설을 만드는 공정 |
| 장비 제조·설치 | 제품별 제조·납품·설치와 시운전 |
| 시공 사례 | 실제 현장의 수행 범위와 사진 |
| 제품몰 | 장비·부품·소모품·간이견적 |

보조 메뉴: 창업 가이드, 사업계획서, 후보지 기록, 노터치 리서치, 회사 소개, 운영 앱, 개인정보 안내. GPT 사이트 메뉴는 제외한다.

PC는 로고·주요 메뉴·상담 버튼을 배치한다. 메뉴가 좁아지면 모바일 메뉴로 전환해 단어가 글자 단위로 꺾이지 않게 한다. 모바일은 로고·메뉴 버튼·상담 접근을 제공하고, 메뉴 펼침과 닫힘·키보드 이동을 지원한다.

## 6. 메인페이지 구성

| 순서 | 영역 | 표시 내용과 연결 |
|---|---|---|
| 1 | 대표 화면 | 토목부터 오픈까지 수행한다는 문구, 실제 현장 사진, 셀프·손세차 선택 |
| 2 | 창업 방식 | 셀프·손세차 서비스 카드, 노터치 리서치 보조 카드 |
| 3 | 빅워시의 다섯 공정 | 토목 → 건축 → 장비 제조 → 장비 설치 → 시운전·오픈 |
| 4 | 실제 작업 사례 | 작업 전·공정 중·설치 후 사진과 수행한 내용 |
| 5 | 맡길 범위 선택 | 전체 창업 / 토목·건축 / 장비 제조·납품 / 장비 설치·교체 |
| 6 | 주요 장비 | 실제 취급·제조 품목, 용도와 설치 조건, 제품몰 연결 |
| 7 | 창업 준비 자료 | 입지·계약·사업계획·환경·폐수·공사 준비 |
| 8 | 회사 소개 | 사업 범위·사업자 정보·확인된 과거 활동 |

| 10 | 하단 정보 | 회사 정보·전체 메뉴·연락처·개인정보 안내 |

첫 화면은 회사의 수행 역량과 두 가지 창업 방식에 집중한다. 공정 사진에는 “어느 현장에서 어떤 작업을 했는지” 설명을 붙인다. 실제 사진이 없는 경우 일러스트는 설명용으로 표시하며 시공 실적처럼 사용하지 않는다.

## 7. 셀프세차와 손세차 페이지

두 페이지는 동일한 구조를 사용해 비교하기 쉽게 하되 현장 요구사항은 각각 작성한다.

| 영역 | 셀프세차 | 손세차 |
|---|---|---|
| 소개 | 고객 직접 이용형 공간과 시설 준비 | 작업자가 서비스를 제공하는 공간과 시설 준비 |
| 공간 계획 | 베이 수·진입·대기·드라잉존·기계실 | 작업 공간·작업 인원·대기·실내 청소·장비 배치 |
| 토목·건축 | 바닥·구배·트렌치·배관·기초·건축 공정 | 바닥·배수·작업 공간·건축 공정 |
| 장비 구성 | 세차 설비·폼·결제·온수·청소·폐수 등 | 고압세척기·청소기·콤프레셔·폐수 등 |
| 제조·설치 | 품목별 제작·납품·현장 연결·설치 | 품목별 제작·납품·현장 연결·설치 |
| 오픈 준비 | 시운전·사용 안내·운영 준비 항목 | 시운전·사용 안내·작업 준비 항목 |
| 사례 | 해당 방식의 실제 수행 현장 | 해당 방식의 실제 수행 현장 |
| 상담 | 전체 창업과 공정별 의뢰 | 신규 창업과 기존 매장 개선 |

제품군은 상담으로 현장에 맞춰 구성한다. 모든 장비가 필수이거나 모두 자체 제조인 것처럼 표시하지 않는다. 미정인 면적·인원·비용은 고객 가정과 현장 견적을 구분한다.

페이지 하단은 “이 방식으로 상담하기”와 “필요 장비 보기”를 제공한다. 상담에 전달할 세차 방식은 미리 선택하되 사용자가 변경할 수 있게 한다.

## 8. 토목·건축과 장비 제조·설치

### 토목·건축 페이지

공정 흐름: 현장 조건 확인 → 범위·도면·견적 협의 → 필요한 행정절차 확인 → 토목·건축 → 설비 설치 인계.

주요 설명은 부지 상태, 철거 필요 여부, 바닥·배수·집수·배관, 구조물과 기계실, 전기·급수 등 공정 간 연결이다. 프로젝트별 빅워시 계약 범위와 외부 전문업체·고객 준비사항을 안내한다. 현장별 인허가 협의는 공사와 구분해 설명한다.

### 장비 제조·설치 페이지

제품군별로 제조·조립, 공급, 현장 설치, 배관·전원 연결, 시험 운전과 사용 안내를 설명한다. 자체 제조 제품에는 모델과 실제 제작 자료를 표시하고 공급 제품은 제조사와 판매·설치 역할을 구분한다.

고객은 전체 장비 구성, 단품 납품, 기존 장비 교체, 설치 의뢰 중 필요한 범위를 선택할 수 있다. 납기·설치비·운송·부가세·AS 조건은 견적에 포함해 확인한다.

### 오픈 준비

설치 후 시운전, 장비 사용 안내, 운영 준비 목록과 인수 확인으로 연결한다. 사업자등록·보험·환경시설 가동 등 필요한 절차의 확인 주체를 표시한다. 일괄 대행이나 승인 보장을 의미하는 문구는 실제 제공 범위가 확정된 경우에만 사용한다.

## 9. 시공 사례와 신뢰 자료

사례 한 건은 다음 정보를 갖춘다.

- 현장명 또는 공개 가능한 별칭, 지역과 수행 시기
- 셀프·손세차·복합 등 방식
- 신설·리뉴얼·부분 공사·장비 납품 등 의뢰 유형
- 빅워시가 실제 수행한 공정
- 설치·납품 장비와 제조·공급 역할
- 작업 전·공정 중·완료 사진 및 설명
- 현장 조건, 해결한 과제, 상담 연결

전체 시공과 장비만 납품한 사례를 명확히 구분한다. 고객명·상세 주소·인물·차량번호는 공개 범위를 확인한다. 실적 건수와 성과 수치는 확인된 집계만 표시한다.

사례가 확보되기 전에는 검증 가능한 제품·제작·설치 설명을 먼저 제공한다. 교육·전문지 활동은 연혁에 연도와 출처를 적고 현재 진행 중인 행사처럼 표시하지 않는다.

## 10. 제품몰과 상담

제품몰은 장비·부품·소모품 판매 창구로 유지한다. 기존 장바구니·수량·간이견적·인쇄 기능을 보존하고 서비스 페이지에서 관련 제품으로 연결한다. 공사 전체 견적은 단품 장바구니 합계와 구분한다.

상담 항목:

| 항목 | 입력 방식 |
|---|---|
| 세차 방식 | 셀프 / 손세차 / 복합 / 미정 |
| 요청 범위 | 전체 진행 / 토목·건축 / 장비 제조·납품 / 설치·교체 / 오픈 준비 |
| 현재 단계 | 구상 / 후보지 검토 / 계약 전후 / 공사 준비 / 운영 중 |
| 현장 | 지역, 후보지 확보 여부, 상세 주소 선택 |
| 규모·일정 | 예상 규모·베이·희망 일정, 모르면 미정 |
| 연락 | 이름·연락처, 이메일은 필요한 경우 선택 |
| 추가 자료 | 사진·도면·요청사항 선택 |

상담은 범위와 지역·연락처부터 입력하고 세부 자료는 선택으로 받는다. 제출 전에 전달 내용을 보여주고 서버 저장 성공 후에만 접수번호를 표시한다.

GitHub Pages는 상담 서버가 없으므로 운영 상담 사이트로 연결한다. 두 사이트의 브라우저 기록은 자동 공유되지 않음을 표시한다. 이번 기획으로 운영 사이트를 변경하거나 자동 전송 기능을 도입하지 않는다.

## 11. 창업 도구와 기존 페이지 이전

현재 GitHub 배포본의 20단계는 노터치·손세차 복합 준비에 맞춰 작성된 자료다. 단순히 “노터치”를 “세차장”으로 치환하지 않는다.

| 기존 자료 | 변경 원칙 |
|---|---|
| 메인 이름·공통 회사 소개 | 세차장 전체 범위로 변경 |
| 노터치 리서치 | 기존 제목·본문·출처 유지 |
| 20단계·사업계획 | 적용 방식을 표시해 보존, 셀프·손세차 전용 흐름 추가 |
| 기존 저장 기록 | 저장 키와 구조를 보존하거나 검증된 이전 적용 |
| 실무 체크리스트 | “실무 체크리스트”로 정확히 표시 |
| 후보지 입력 | 실제 후보지 이름·주소 입력 영역으로 직접 연결 |
| 기존 URL·북마크 | 작동 유지 또는 목적지 대응표에 따른 연결 |

현재 “후보지 확인” 버튼이 일반 실무자료로 연결되는 부분은 실제 입력 영역으로 조정한다. 모든 페이지의 로고·홈·상담 메뉴를 공통화하며 리서치 페이지에서 복구한 홈 이동도 유지한다.

기존 dclub 사이트와 GitHub Pages는 별도 배포 대상으로 관리한다. 초기 개편은 GitHub Pages에 적용하고 운영 상담 사이트 변경은 별도 구현 범위로 정한다.

## 12. 화면 경로 제안

다음은 신규 제작 시 사용할 경로 제안이며 아직 공개된 페이지를 뜻하지 않는다.

서비스 페이지는 초기 HTML에 제목·요약·본문·내부 링크를 제공한다. 제품과 사례에는 구체적인 현장·모델·수행 역할을 담아 검색 의도를 구분한다.

## 13. 제작 순서

| 단계 | 작업 | 완료 결과 |
|---|---|---|
| 1 | 이번 기획을 기준으로 구현명세·작업 범위 작성 | 메뉴·경로·데이터·보존·검증 기준 |
| 2 | 메인·공통 메뉴·셀프·손세차 페이지 | 사업 범위와 창업 방식 구분 |
| 3 | 토목·건축·장비 제조·설치·회사 소개 | 전체 진행과 부분 의뢰 안내 |
| 4 | 실제 현장·제작 사진과 사례 정리 | 수행 범위가 확인되는 사례 |
| 5 | 방식별 준비 도구와 상담 연결 조정 | 기록 보존과 정확한 목적지 |

공사·제조·설치의 설명 페이지는 우선 작성할 수 있다. 실제 사례는 확보된 자료부터 채운다. 현장 사진·제작 사진, 공개할 사례, 공정별 계약 범위, 대표 연락처·AS 조건은 콘텐츠 제작 시 사업주 자료로 구체화한다.

## 14. 완료 기준

- 처음 방문한 사람이 빅워시가 토목부터 오픈까지 진행하는 회사임을 알 수 있다.
- 셀프·손세차 서비스와 노터치 리서치의 역할이 구분된다.
- 전체 진행과 공정·장비별 의뢰가 모두 안내된다.
- 모든 페이지에서 로고·홈을 통해 메인으로 돌아올 수 있다.
- GPT 사이트 메뉴가 다시 노출되지 않는다.
- 후보지 확인 버튼은 실제 입력 영역, 제품 버튼은 해당 제품, 상담 버튼은 실제 상담 창구로 연결된다.
- 360·390·768·1440px 화면에서 메뉴와 버튼이 겹치거나 글자 단위로 무너지지 않는다.
- 기존 후보지·사업계획·체크·장바구니 기록이 유지된다.
- 실제 제조·공급·시공 역할과 사례 사진 설명이 일치한다.
- 빌드·링크·화면·저장 복원·배포 확인을 수행하고 미검증은 별도 표시한다.
