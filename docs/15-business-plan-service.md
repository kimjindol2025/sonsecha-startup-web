# 나의 손세차장 사업계획서 서비스

## 목적

빈 문서 양식을 제공하는 것이 아니라, 예비 창업자가 기본 질문에 답하고 공식 자료를
확인하면서 자금·지역·규모·일정·예산·수익 가정을 자기 계획으로 정리하게 한다.

## 사용자 흐름

1. 기존 후보지를 선택하거나 후보지 없이 독립 계획서를 만든다.
2. 자기자금, 희망 지역, 세차장 형태, 평수, 베이 수, 준비기간, 공사기간과 개업
   예정일을 입력한다.
3. 임대·설계·공사·폐수처리·장비·인테리어·용품·보험·홍보·운전자금·예비비를
   항목별로 입력한다.
4. 자기자금·대출·지원금 계획과 비교해 예상 부족분을 확인한다.
5. 객단가·차량 수·영업일·월 운영비를 입력해 단순 월 매출과 잔액을 계산한다.
6. 공식 상권·통계·지원사업·정책자금 자료를 확인하고 조사 결과를 직접 기록한다.
7. 입력값이 사업 개요, 준비 일정, 상세 예산, 자금 조달, 매출·운영비, 시장 조사,
   후보지 12단계 기록, 위험요인과 실행계획으로 자동 정리된 전체 초안을 확인한다.
8. 보완할 항목 목록을 확인하고, 완성 문서를 복사하거나 인쇄·PDF로 저장한다.

## 자동 정리 문서

사업계획서 하단 문서는 별도의 생성 요청 없이 입력과 동시에 갱신된다. 입력하지 않은
사실을 만들어 내지 않으며 빈 핵심 항목은 `확인 필요`로 표시한다.

- 사업계획 요약
- 사업 개요와 서비스 구상
- 준비·공사·개업 일정
- 14개 창업예산 항목과 자금 조달 부족분
- 객단가·차량·영업일 가정과 8개 월 운영비 항목
- 시장·상권 조사 메모
- 연결 후보지의 1~12단계 체크·판정·세부 메모
- 공식 자료 확인 경로
- 위험요인, 다음 행동, 작성 전 보완 항목

`내용 복사`는 요약만이 아니라 위 전체 내용을 텍스트로 복사한다. `인쇄 · PDF`는 입력
폼을 제외하고 정리된 전체 문서만 출력한다.

## 저장과 개인정보

- 저장 키: `sonsecha-business-plans-v1`
- 기존 후보지 저장 키와 구조를 변경하지 않는다.
- 사업계획서는 브라우저에만 자동 저장하며 서버로 자동 전송하지 않는다.
- 여러 계획서는 `id` 단위로 분리한다.
- 후보지 연결은 사용자가 `후보지 기본정보 불러오기`를 눌렀을 때만 주소·형태·베이
  정보를 복사한다.

## 공식 리서치 출처

- [소상공인 상권정보시스템](https://bigdata.sbiz.or.kr/): 상권·업종·경쟁 확인
- [통계청 SGIS 업종통계지도](https://sgis.kostat.go.kr/view/indrStats/indrStatsMap):
  인구·가구·사업체·생활권역 통계 확인
- [K-Startup 창업지원포털](https://www.k-startup.go.kr/web): 지원사업 공고와 전문가
  상담 확인
- [소상공인정책자금](https://ols.semas.or.kr/ols/man/SMAN018M/page.do): 정책자금,
  금리, 신청 안내와 상환스케줄 확인

외부 자료는 확인 경로를 제공하는 것이며, 지역명만으로 자동 결론을 만들지 않는다.
지원사업 선정, 대출 승인, 허가 가능 여부를 확정값으로 표시하지 않는다.

## 예시 금액 원칙

`작성 예시 넣기`를 사용자가 직접 눌렀을 때만 값이 채워진다. 예시값은 견적이나 평균
창업비가 아니라 계산 방법을 보여주기 위한 가정이다. 실제 계획에서는 후보지 조건,
도면, 관할기관 답변과 현장 견적으로 전부 교체해야 한다.
