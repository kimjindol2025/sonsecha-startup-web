# 로그인 없는 진행판 체험판 배포 준비

2026년 11월 7일 한국시간. Kim의 GitHub push·배포 요청에 맞춰 공개 가능한 정적 체험판을 준비했어요. 현재는 로컬 준비와 검증 상태이며 실제 push·배포는 실행하지 않았어요. 공개 저장소로 소스·문서·시험 자료를 올리는 작업이 자동 승인 검토에서 거부돼 정확한 목적지·자료 범위의 승인이 필요해요.

## 공개본 동작

`workspace.html`은 공개 도메인에서 IndexedDB를 사용하는 브라우저 체험판으로 실행돼요. `src/workspace-browser-store.js`가 사업·후보지·체험 의뢰·답변·사진을 현재 브라우저에만 저장해요. 실제 검토 담당자에게 전송하지 않으며 의뢰 번호는 `DEMO-`로 구분해요. 고객·책임자·담당자 화면 선택도 현재 브라우저에 저장된 예시 자료의 화면을 살펴보는 기능이에요. 이를 실제 직원 신원 확인이나 서버 권한 검사로 표시하지 않아요.

기존 로컬 서버 시험 모드는 localhost에서 계속 사용할 수 있고, `?storage=browser`로 정적 체험판을 시험할 수 있어요. 서버의 production 차단을 해제하지 않았고, 운영 서버에는 시험 역할 선택 API를 추가하지 않았어요. 공개본에는 브라우저 저장과 실제 접수가 다르다는 안내를 표시해요. 기존 창업가이드·실제 접수·상품·관리자 기능은 유지해요.

## 두 가지 소스 기준

개발 브랜치 `feat/prd-v3-review-workspace`는 현재 손세차장 운영 소스를 기준으로 이전 수정과 새 진행판을 보존해요. GitHub `master`의 다른 작업을 덮어쓰지 않기 위해 공개 배포용 `release/workspace-experience`는 GitHub의 기존 `4618238`에서 별도로 만들었어요.

공개 배포용 브랜치에는 새 진행판 HTML·JavaScript·CSS와 파비콘, 기존 메뉴의 체험판 링크, Vite 입력·GitHub Pages 기본 경로만 추가해요. 기존 앱 목록과 보고서·운영 앱 파일, 기존 Node 서버는 변경하지 않아요. GitHub Pages의 기존 master push 워크플로를 그대로 사용하며 워크플로와 저장소 공개 설정은 바꾸지 않아요.

원래 요청 대상 `https://sonsecha.dclub.kr/`에는 별도로 준비한 루트 경로용 정적 파일 묶음을 사용할 수 있어요. 서버가 정적 파일을 요청할 때 읽는 구조이므로 해당 묶음 반영에는 PM2·nginx·공유 hook·watcher 재시작이 필요하지 않아요. 실제 반영 전에 원본 파일 해시를 다시 비교하고 대상 파일을 백업해야 해요. 현재는 묶음·원본 해시만 준비했어요.

## 검증

- GitHub Pages 경로 `/sonsecha-startup-web/`를 모사한 localhost 정적 서버에서 체험 흐름 7항목 통과.
- 브라우저 저장 실패 때 입력 유지와 재시도, `DEMO` 번호 생성, 예시 역할 배정·답변·메모 분리, 새로고침 복원, 재문의 번호 유지, 390px 표시·Esc 초점 복귀 확인.
- 체험 흐름에서 `/api/workspace` 네트워크 요청 0건, 실제 외부 연락 0건, JavaScript 예외 0건.
- 별도 시험 브라우저에서 기존 브라우저의 예시 자료가 나타나지 않는 것 확인.
- 루트 경로 빌드와 GitHub Pages 경로 빌드 성공. 결과·화면은 `evidence/public-browser-results.json`, `evidence/workspace-public-mobile.png` 참조.

IndexedDB는 브라우저 저장 공간·설정·사이트 데이터 삭제의 영향을 받아요. 다른 기기로 이어쓰기, 실제 고객 접수·직원 배정·통지, 서버 백업은 이 체험판 기능이 아니에요. 원래 v3의 실제 고객 업무는 기존 서버 개발본에 로그인·신원 경계를 연결하는 별도 범위로 남아 있어요.

## 남은 실행 단계

공개 GitHub 저장소 `kimjindol2025/sonsecha-startup-web`에 소스·문서·합성 시험 화면을 올리는 범위와 체험판 공개를 명시적으로 승인받아야 해요. 승인 전에는 GitHub push·Actions 실행·운영 정적 파일 반영을 하지 않아요. Gogs push는 사용자 요청이 GitHub로 바뀌었으므로 재시도하지 않아요.
