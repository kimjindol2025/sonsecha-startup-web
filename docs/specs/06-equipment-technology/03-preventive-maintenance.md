# [기획서] 세차장 예방정비 앱

> **카테고리**: 06 장비·기술 서비스 (C급 · 확장)  
> **앱 ID**: `app-preventive-maintenance`  
> **문서 상태**: 조사 초안 — 브라우저 데모 구현은 [구현 명세 v1.0](./03-preventive-maintenance-implementation.md)을 따른다. OEM 정비 주기와 현장 적용은 확인 전.  
> **목적**: 장비별 제조사 정비 기준과 사용시간·달력 주기를 관리하고, 작업·부품·가동중단 이력을 남긴다.

## 1. 제품 범위

> 구현자는 OEM 기준을 추정하지 않는다. 데모 일정, 화면 흐름과 수용 기준은 [구현 명세 v1.0](./03-preventive-maintenance-implementation.md)에 정의했다.

기존 일일점검·운영 기록과 중복을 줄이기 위해 이 앱은 **예정된 정비 작업의 계획·기한·완료 이력**에 집중한다. 장비 고장 원인을 AI로 진단하는 기능은 AI 고장진단 앱의 범위다. 정비 주기는 범용 기준으로 임의 제공하지 않고 장비 제조사·모델별 OEM 지침과 현장 승인 기준으로 설정한다.

주요 사용자는 점주/시설관리자, 현장 작업자, 장비 제조사·정비 기사, 다지점 본사 담당자다. 관리자는 일정을 승인하고, 작업자는 체크리스트와 증빙을 남기며, 기사는 전문 작업과 교체 부품을 기록한다. 본사 사용자는 권한이 부여된 지점의 현황을 조회한다.

## 2. MVP 기능

- 장비 제조사·모델·일련번호·설치일과 매뉴얼 URL/버전 등록
- 제조사·모델별 정비 작업 템플릿과 출처, 적용 조건, 안전·자격 요건 저장
- 달력 기한 또는 검증된 운전시간 기준으로 예정/임박/연체 상태 계산
- 운전시간은 현장 컨트롤러가 제공하는 경우 출처와 동기화 시각을 남기고, 미연동이면 수동 입력을 지원
- 담당자 지정, 작업 체크리스트, 측정값·메모·사진·사용 부품·작업시간 기록
- 작업 완료 시 다음 정비일/운전시간 예정 생성, 연기 사유와 승인 기록
- 장애 발견 시 기존 장비 AS 관리 흐름으로 전달
- 계획정비·비계획 정지·반복 장애·정비비용 보고

## 3. 주요 업무 흐름

1. 관리자가 장비 모델과 최신 제조사 매뉴얼을 등록한다.
2. 정비 템플릿의 작업·주기·적용 조건·안전 안내를 검토하고 승인한다.
3. 시스템은 달력 또는 가동시간 기준으로 다음 작업 시점을 계산한다.
4. 담당자가 작업을 수행하고 수치·사진·교체 부품·소요 시간·발견된 이상을 기록한다.
5. 관리자는 증빙을 확인해 완료 또는 보완 요청하고, 후속 AS가 필요하면 티켓을 생성한다.

## 4. 데이터 모델과 품질 규칙

핵심 엔터티는 `site`, `equipment`, `equipment_model`, `maintenance_template`, `maintenance_task`, `meter_reading`, `work_order`, `part_usage`, `downtime_event`, `manual_reference`, `user_role`이다. 템플릿에는 출처 URL/문서 버전, 유효일, 작업 주기와 시간·조건 단위, 모델 적용 범위, 주의사항을 필수로 기록한다. 운전시간 값에는 계측 출처와 마지막 동기화 시각을 붙이고, 불확실한 수기 값은 자동 계량값과 구분한다.

예방정비 주기가 없는 장비는 관리자가 임의의 권장 주기를 선택하도록 안내하지 않는다. 제조사 자료가 없으면 “주기 미확인” 상태로 표시하고 정비 책임자에게 기준 확인을 요청한다.

## 5. 안전과 지표

정비 전 전원 차단·압력 해제 등 작업 안전 절차는 장비별 제조사 문서와 사업장 안전 절차에 연결한다. 앱은 작업 자격이나 안전한 작업을 대신 판정하지 않는다. 오일 종류나 교체주기 변경이 제조사 보증에 영향을 줄 수 있으므로 적용 전 해당 장비 매뉴얼과 제조사에 확인한다.

파일럿에서 기준선을 정할 지표는 기한 내 작업 완료율, 연체 장비 수/기간, 정비기록 완결률, 계획정비 대비 비계획 정지시간, 반복 장애, AS 호출·수리 소요시간, 정비비용이다. 근거 없는 “고장률 감소율”이나 절감률은 제품 성과로 약속하지 않는다.

## 6. 사업 가설 및 검증 질문

**수익 가설**: 지점/장비 단위 정비 캘린더 구독, 초기 장비·정비 템플릿 설정, 제조사·정비 파트너의 작업 이력/점검 서비스 연계를 검토한다. 가격과 ROI는 아직 조사로 확인되지 않았다.

- 점주와 기사는 현재 정비 주기·연체·부품 사용을 어디에서 기록하는가?
- 세차장 펌프·콤프레셔·보일러 제조사/모델 매뉴얼을 현장에서 확보할 수 있는가?
- 장비 컨트롤러의 운전시간 카운터/API가 실제로 제공되는가? 수동 입력은 얼마나 받아들일 수 있는가?
- 오일·필터·벨트 등 소모품 품번과 대체품 승인 기준은 무엇인가?
- 작업 전 안전 확인·전문 자격·보증 조건은 모델별로 무엇인가?
- 정비 연기 승인자, 작업 증빙, 비용·다운타임 기록을 누가 책임지는가?
- 비용 지불자는 점주·본사·정비업체 중 누구이며 어떤 과금 단위가 적절한가?

## 7. 단계별 실행

| 단계 | 실행 내용 | 완료 기준 |
| --- | --- | --- |
| 0. 자료 확보 | 점주·기사 인터뷰, 대표 모델과 OEM 매뉴얼·보증 조건 수집 | 주기·안전 근거가 붙은 템플릿 후보 확보 |
| 1. 수기 파일럿 | 장비 등록, 제조사 기준 정비 캘린더, 작업 증빙·연체 관리 | 현장 기록 부담과 누락 개선 여부 측정 |
| 2. 운전시간 연동 | 지원이 확인된 모델만 계량값 자동 수집 | 자동/수기 값 정확성·유지 비용 확인 |
| 3. 다지점 서비스 | 권한, AS 티켓 연계, 부품·다운타임 리포트 | 반복 사용과 유료 운영 의향 확인 |
