# [기획서] 세차장 IoT 장비관리

> **카테고리**: 06 장비·기술 서비스 (C급 · 확장)  
> **앱 ID**: `app-iot-equipment-management`  
> **문서 상태**: 조사 기반 초안 — 센서·장비 호환성과 인증 범위 현장 확인 필요  
> **목적**: 펌프·콤프레셔·보일러·수조 등 설비의 센서값과 연결 상태를 모아 이상 징후를 일찍 발견하고 점검을 기록한다.

## 1. 문제와 사용자

세차장 설비 고장과 동파·수위 문제는 현장 순찰 전까지 발견되지 않을 수 있다. 기존 장비에 센서나 공개 통신 인터페이스가 있는지는 모델마다 다르며, 국내 세차장 설비의 설치 환경·보증 조건·통신 품질은 조사만으로 확인되지 않았다.

| 사용자 | 주요 작업 |
| --- | --- |
| 점주·현장 관리자 | 설비 상태와 경보 확인, 점검·조치 기록 |
| 본사 운영 담당 | 여러 지점 센서 상태와 반복 이상 비교 |
| 설치·정비 기사 | 센서 등록·교체·교정, 장애 원인 확인 |

## 2. MVP 범위

- 한 파일럿 매장에서 데이터 접근이 가능한 설비 2~3종부터 선정한다.
- 후보 데이터: 펌프 운전 상태/전류/압력, 콤프레셔 압력/운전시간, 보일러 온도, 동파방지 구역 온도, 원수·폐수조 수위. 장비 모델별 제공 가능성을 먼저 조사한다.
- 센서 온라인 상태, 마지막 수신 시각, 값·단위·측정 품질 표시
- 설정 가능한 임계치, 이상 알림, 확인자·현장조치·사진 기록
- 센서 교체·교정·배터리 및 점검 주기 기록
- 통신 중단 시 경보와 데이터 지연 여부 표시, 게이트웨이 로컬 버퍼 후 연결 복구 시 재전송

MVP는 모니터링·점검 기록만 지원한다. 센서나 릴레이로 히터·펌프를 자동 제어하는 기능은 제외한다.

## 3. 연동과 데이터

기존 PLC/컨트롤러가 제조사 승인 하에 제공하는 읽기 전용 연결을 우선 검토한다. Modbus RTU/TCP, OPC UA는 후보일 뿐이며 실제 설치 장비가 이를 지원한다는 근거는 아직 없다. 지원 인터페이스가 없으면 설치·전기·기계 안전 및 보증 유지 조건을 확인한 별도 센서와 현장 게이트웨이를 검토한다.

데이터 모델은 `site`, `equipment`, `sensor`, `measurement`, `threshold`, `alert`, `inspection`, `calibration`을 포함한다. 측정치에는 장비·센서 ID, 값, 단위, 측정 시각, 수신 시각, 품질/오류 플래그, 임계치 버전을 함께 기록한다. 통신 두절과 센서 자체 이상을 정상값과 구분해야 한다.

## 4. 보안·안전·국내 적합성 확인

- PLC/RTU를 인터넷에 직접 연결하지 않고 제어망 분리, 방화벽, 최소 권한과 읽기 전용 접근을 우선한다.
- 기기 고유 식별, 인터페이스 접근 통제, 전송 데이터 보호, 보안 업데이트와 장치 상태 확인을 요구사항으로 둔다.
- 무선 센서·게이트웨이를 제조·수입·판매하는 구성은 전파법 적합성평가 대상이 될 수 있다. 전원·제품 구성에 따른 KC 안전관리 적용도 확인해야 한다. 이 문서는 특정 센서 설치가 인증 면제 또는 적법하다고 판단하지 않는다.
- 센서 설치 위치, 방수·방진·온습도 조건, 전기 안전, 제조사 보증 영향은 현장과 장비 제조사에 확인한다.

## 5. 운영 흐름과 지표

1. 관리자가 지점과 장비 모델을 등록하고 센서/인터페이스 가능 여부를 확인한다.
2. 설치 기사가 승인된 방법으로 연결한 뒤 단위·정상 범위·통신 장애 감지를 점검한다.
3. 이상값 또는 센서 오프라인이 발생하면 담당자에게 알림을 보내고 확인·조치 이력을 남긴다.
4. 월간 리포트에서 수집 가능률, 경보 확인 시간, 오탐/미탐, 점검 완료율을 검토한다.

초기 KPI 기준값과 경보 임계치는 파일럿에서 정한다. 지표 후보는 센서 데이터 수집 성공률, 오프라인 탐지 시간, 유효 경보 비율, 문제 발견부터 조치까지 시간, 동파·수위 사고의 사전 발견 건수다.

## 6. 사업 가설과 검증 질문

**수익 가설**: 센서·게이트웨이 설치 및 초기 교정비와 장비/지점 단위 구독, 선택적 정기 점검을 묶는다. 실제 가격과 투자 회수 기간은 확인되지 않았다.

- 현재 보유 설비에 경보 출력 또는 센서가 있는 비율은 얼마인가?
- 어떤 동파·수위·압력·온도 사고가 언제 발견되며, 현재 경보는 어디로 전달되는가?
- 장비 모델별 Modbus/OPC UA/접점 출력과 유지보수 보증 조건을 제공할 수 있는가?
- 설치 승인과 책임자는 누구이며, 유선·Wi-Fi·LTE 중 현장에서 안정적인 연결은 무엇인가?
- 센서 이상/오탐 시 점주가 필요한 대응 절차와 허용 가능한 경보 빈도는 무엇인가?
- 고객은 센서 설치비, 지점 구독, 장비별 구독 중 어떤 비용 기준을 선호하는가?

## 7. 단계별 실행안

| 단계 | 실행 | 완료 기준 |
| --- | --- | --- |
| 0. 현장 조사 | 점주 3~5곳과 제조사 2곳 인터뷰, 장비 모델·매뉴얼·센서 출력 확인 | 설치 가능 센서 후보와 보증/인증 검토 목록 확보 |
| 1. 계측 파일럿 | 2~3개 설비 유형에서 수집·임계치·알림·점검 이력 검증 | 데이터 품질과 경보의 현장 유용성 확인 |
| 2. 운영 제품화 | 다지점 권한·리포트·교정·설치 파트너 프로세스 | 반복 사용, 지불 의향과 설치 원가 확인 |
