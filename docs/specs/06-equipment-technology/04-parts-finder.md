# [기획서] 세차장 장비 부품 찾기

> **카테고리**: 06 장비·기술 서비스 (C급 · 확장)  
> **앱 ID**: `app-equipment-parts-finder`  
> **문서 상태**: 조사 초안 — 검색/문의 데모 구현은 [구현 명세 v1.0](./04-parts-finder-implementation.md)을 따른다. 실제 호환 카탈로그는 미확정.  
> **목적**: 세차장 장비를 정확히 식별하고 해당 모델의 부품 정보와 신뢰 수준을 제공해 공식 문의·판매처 연결을 돕는다.

## 1. 해결하려는 문제

> Codex는 제조사 제품이나 호환 여부를 임의로 채우지 않는다. 데이터/화면/검색 규칙은 [구현 명세 v1.0](./04-parts-finder-implementation.md)에 고정했다.

부품을 찾으려면 장비 명판의 정확한 상품번호·모델 접미어·일련번호와 부품도면을 대조해야 하는 경우가 있다. 제조사 공식 사례에서는 명판 정보나 각인·사진을 통해 모델 확인을 돕고, 전문 장비는 서비스 파트너 문의와 교육된 작업자 교체를 안내한다. 현재 국내 세차장에 보급된 브랜드·모델 분포와 제조사 데이터 접근권은 아직 확인되지 않았다.

대상은 부품을 찾는 점주·현장 직원, 장비를 수리하는 AS 기사, 부품 카탈로그와 판매 정보를 제공하는 제조사·딜러, 데이터 근거를 검수하는 플랫폼 운영자다.

## 2. MVP 검색 흐름

1. 장비군과 제조사를 선택하고 모델·세부 사양(suffix)·일련번호·연식을 입력한다.
2. 명판 또는 각인 사진을 추가해 모델을 식별한다. 사진 판독 결과는 확정 정보가 아니라 사용자가 확인해야 할 후보로 표시한다.
3. 확인된 모델 전용 부품도면·부품번호를 기준으로 부품 범주와 위치 번호를 검색한다.
4. 결과에 순정 부품, 문서 근거가 있는 호환품, 미검증 판매자 정보를 구분해 출처와 적용 모델을 표시한다.
5. 정확히 일치하는 모델/부품 근거가 없으면 유사 상품을 추천 확정하지 않고 제조사·딜러 문의로 연결한다.

초기에는 검색과 공식 문의/상담 연결에 집중한다. 온라인 결제, 실시간 재고, 즉시 호환 판정은 판매처 계약과 데이터 권한을 확보한 뒤 추가한다.

## 3. 결과 표시 및 안전 규칙

- **OEM 순정부품**: 제조사 카탈로그 또는 승인된 판매처 자료로 확인된 경우만 표시
- **문서 근거 호환품**: 특정 모델·세부 사양에 호환됨을 공급자가 제공한 문서로 확인한 경우 표시
- **호환 검증 불가**: 모델 적용 근거가 없거나 오래되어 현재 유효성을 확인하지 못한 경우 명확히 표시
- ‘순정’, ‘제조사 승인’, ‘정품’ 표시는 실제 증빙과 권한이 있을 때만 사용한다.
- 고압·전기·가스·회전부·압력 안전에 영향을 주는 부품은 모델명이나 증상 유사성만으로 대체품을 추천하지 않는다.
- 설치 자격, 보증, 지역·판매처 조건을 확인할 수 없는 경우 문의가 필요하다고 안내한다.
- 상표 사용·호환 설명·판매 책임은 국내 법률 및 파트너 계약 검토 후 확정한다.

## 4. 데이터와 운영

핵심 엔터티는 `equipment_model`, `equipment_variant`, `nameplate`, `parts_diagram`, `part`, `part_alias`, `compatibility_claim`, `evidence_source`, `seller`, `offer`, `inquiry`, `catalog_revision`이다. 모델에는 제조사·모델명·suffix·일련번호 범위·연식과 명판 사진을, 부품에는 부품번호·도면 위치·재질/규격·단종/대체 번호를 기록한다.

호환성 주장에는 적용 모델 목록, 근거 문서·버전·발행/확인일, 데이터 제공자, 검수자와 신뢰 상태를 필수로 둔다. 가격·재고·지역·반품·보증·주문 링크도 판매처와 최종 갱신 시각을 함께 표시한다.

운영자는 제조사/딜러가 제공한 카탈로그를 승인된 범위에서 등록하고, 품번·도면·적용 모델·문서 버전을 검증한다. 사용자의 부품 식별/호환 오류 신고는 카탈로그 수정 검토로 연결한다. 단종품과 대체품의 관계는 이전 기록을 보존하며 수정 이력을 남긴다.

## 5. 성공 지표

- 사용자 또는 딜러가 확인한 장비 모델 식별 완료율
- 검색 후 정확한 부품번호 확인까지 도달한 비율
- 모델 불일치 오추천·반품·호환 클레임률
- 카탈로그 근거 문서가 유효한 결과의 비율
- 문의 연계 응답시간과 조달 리드타임(파트너 데이터가 확보된 경우만 측정)

거래액이나 시장 규모, 시간 절감률은 근거가 없어 약속하지 않는다. 기준값과 목표는 국내 장비·딜러 파일럿 뒤 정한다.

## 6. 수익 가설과 검증 질문

**수익 가설**: 제조사·딜러가 제공하는 공식 문의 리드, 승인된 판매처 연결 수수료, 파트너 카탈로그 운영 도구를 검토한다. 수수료·가격 데이터와 판매 연결 권한은 확인되지 않았다.

- 국내 셀프/노터치 세차장에 많이 보급된 장비 제조사·모델·연식은 무엇인가?
- 현장에서 부품 문의 시 필요한 식별정보와 사진은 무엇이며, 실제 탐색에 얼마나 걸리는가?
- 제조사·딜러가 부품도면·적용 모델·대체 번호·재고·가격을 제공할 수 있는가?
- 순정품과 호환품의 근거·보증·반품 책임자는 누구인가?
- 사진만으로 식별할 수 없는 부품군은 무엇이며 어떤 확인 절차가 필요한가?
- 상표·제조사 로고·호환 표기와 카탈로그 재사용 허가 조건은 무엇인가?
- 점주·기사는 검색, 사진 문의, 전화 연결 중 어떤 경로를 선호하는가?

## 7. 단계별 실행안

| 단계 | 실행 | 완료 기준 |
| --- | --- | --- |
| 0. 공급 데이터 확인 | 장비점·부품 딜러 인터뷰, 샘플 카탈로그와 이용 권한 협의 | 모델/품번/호환 근거를 합법적으로 사용할 수 있는 범위 확정 |
| 1. 검색·문의 MVP | 제한된 장비 모델 카탈로그, 명판 사진, 문의 연결 | 모델 일치율·오추천률·문의 응답 흐름 확인 |
| 2. 딜러 데이터 연동 | 승인된 재고·가격·배송/반품 정보 연결 | 데이터 갱신 책임과 주문·보증 절차 합의 |
| 3. 거래 확장 | 계약에 따른 주문/결제 또는 파트너 연계 | 반품·분쟁·안전 책임과 운영 수익성 검증 |
