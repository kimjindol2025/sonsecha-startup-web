# [기획서] 세차장 AI 고장진단 보조

> **카테고리**: 06 장비·기술 서비스 (C급 · 확장)  
> **앱 ID**: `app-ai-fault-diagnosis`  
> **문서 상태**: 조사 초안 — 데모 구현은 [구현 명세 v1.0](./05-ai-fault-diagnosis-implementation.md) 범위로 제한한다. 실제 AI 진단 승인/자료 미확정.  
> **목적**: 증상과 계측 정보를 OEM 매뉴얼에 연결해 고장 원인 후보와 안전한 다음 확인 단계를 제시한다.

## 1. 제품 원칙과 사용자

> 이 구현 명세는 AI/장비 연결 없는 데모 흐름만 정의한다. 실제 고장 판단을 구현한다고 해석하지 말고, 구체 수용 기준은 [구현 명세 v1.0](./05-ai-fault-diagnosis-implementation.md)을 따른다.

이 앱은 고장 원인을 확정하거나 장비를 자동 제어하는 진단기가 아니라 **정비 판단 보조 도구**다. 한 증상에 여러 원인이 있을 수 있고, 사진만으로 내부 씰·밸브·압력 상태를 알 수 없다. 모델·측정값·근거가 부족하면 추측을 이어가지 않고 판단을 보류해 제조사 또는 공인 AS로 연결한다.

사용자는 점주·현장 직원(증상·수치·사진 제출), 장비 제조사/공인 AS 기사(원인·조치 검토), 다지점 관리자(반복 증상 추적), 콘텐츠 운영자(OEM 출처·모델 적용 범위 갱신)다.

## 2. MVP 대상과 흐름

초기에는 한국어 OEM 문서와 전문가 검수가 확보된 펌프 모델의 제한된 증상군(저압, 맥동, 외부 누수, 이상소음)부터 시작한다. 다른 제조사·모델·보일러·가스·전기·회전체 진단으로 자동 확장하지 않는다.

1. 사용자가 제조사·정확 모델/세부 사양, 증상, 발생 조건, 최근 압력·유량 등 측정값, 이전 작업을 입력한다.
2. 명판/외부 상태 사진을 추가할 수 있으며, 사진 판독은 모델 후보·외관 정보 보조에만 쓴다.
3. 시스템은 모델과 데이터가 일치하는 OEM 매뉴얼 항목을 검색해 원인 후보, 확인 근거, 안전한 비분해 확인 항목과 추가 질문을 제시한다.
4. 결과에는 사용한 문서·개정 정보·해당 항목과 모델 일치 수준을 표시한다.
5. 정보 부족·문서 범위 밖·저신뢰 상황에는 원인 후보를 단정하지 않고 판단 보류와 AS 연결을 제공한다.
6. 기사는 실제 원인, 작업, 교체 부품과 정상 복귀 여부를 확인해 정비 이력으로 남긴다.

## 3. 위험 통제와 사람 검토

- 압력 조절, 안전장치/인터록 우회, 전기·가스·보일러·회전체 분해, 위험한 수리 명령은 제안하지 않는다.
- 제조사 안전 공지가 있으면 진단 결과보다 먼저 보여주고, 작업 중단·전원 차단 여부는 모델별 매뉴얼과 현장 절차를 따르게 한다.
- Cat Pumps는 노즐 마모로 인한 압력 저하를 조절밸브 보정으로 보상하지 말라고 경고한다. 제품은 이런 위험을 안전 규칙과 테스트 케이스로 반영해야 한다.
- 설명 없는 단일 정확도/신뢰도 퍼센트 대신 원인 후보 순위, 참고 문서와 해당 항목, 모델·측정 데이터의 일치 수준, 판단 보류 여부를 표시한다.
- 기사 확인 결과와 AI 제안은 구분 저장한다. 검증된 원인·조치가 전문가 확인을 거친 사례만 평가용 데이터로 편입한다.

## 4. 지식 데이터와 평가

데이터 모델은 `equipment_model`, `symptom_case`, `measurement`, `manual_source`, `diagnosis_candidate`, `safety_rule`, `technician_review`, `repair_outcome`을 포함한다. 사례에는 제조사·모델·사양·연식, 증상·발생 조건, 계측값, 문서 버전, 제안 후보, 실제 교환 부품/작업, 전문가 판정과 재발/정상 복귀 결과를 기록한다.

성능 평가 시 같은 장비·매장·유사 사진이 학습과 평가에 섞이지 않게 분리한다. 파일럿 지표는 확정 원인이 있는 사례의 Top-1/Top-3 정확도, 전문가 수정률, 모델/증상별 성능 차이, 안전한 판단 보류 성공률, 위험 작업 지시율(목표 0), 마스킹 누락률, 현장 방문 전 기사 유용성이다. 정확도만으로 출시 여부를 결정하지 않는다.

## 5. 사진·개인정보 처리

정비 사진에 사람 얼굴이나 차량 번호판 등 식별 정보가 포함될 수 있다. 목적·보유기간·삭제 절차·접근권한을 정하고, 업로드 전에 크롭/자동 마스킹을 안내하거나 적용한다. 외부 AI 사업자 전송 여부와 재학습 이용 여부는 분리해 고지·통제하고, 별도 허용이 없으면 사용 사진을 학습에 재사용하지 않는 것을 초기 원칙으로 둔다. 개인정보 처리의 법적 근거·위탁·국외 이전 등은 제품의 실제 흐름을 정한 뒤 국내 검토가 필요하다.

## 6. 수익 가설과 검증 질문

**수익 가설**: 점포/정비팀 단위 구독과 공인 AS 연결 서비스를 검토한다. 공개 자료만으로 국내 수리비 절감·진단 정확도·매출 효과는 확인할 수 없다.

- 현장에서 접수 전에 필요한 모델 식별정보와 계측값은 무엇인가?
- 반복 발생하며 OEM 문서로 안전한 1차 확인을 안내할 수 있는 증상은 무엇인가?
- 사진만으로 진단하면 안 되는 고장군과 필수 현장 계측은 무엇인가?
- 기사/제조사가 제공할 수 있는 한국어 매뉴얼, 오류코드, 확정 원인·작업 결과는 무엇인가?
- 제조사별 모델명·오류코드 차이, 문서 검색·사용 권한은 어떻게 관리되는가?
- 점주가 사진 업로드, 외부 AI 전송, 기록 보존에 기대하는 조건은 무엇인가?
- 원인 후보·OEM 링크·안전 점검표·전문가 연결 중 실제 지불가치는 무엇인가?
