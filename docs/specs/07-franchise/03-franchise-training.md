# [기획서] 가맹점 교육·운영 학습

> **카테고리**: 07 본사·가맹점 서비스 (C급 · 확장)  
> **앱 ID**: `app-franchise-training`  
> **문서 상태**: 조사 초안 — 데모 교육 흐름은 [구현 명세 v1.0](./03-franchise-training-implementation.md)을 따른다. 법정 교육·실제 콘텐츠 미검토.  
> **목적**: 장비·운영·세제 관련 교육 자료를 지점과 역할에 맞게 배정하고, 개정·학습·현장 확인 이력을 관리한다.

## 1. 교육 유형 구분

> 구현 시 법정교육 이수·자격으로 오인되지 않도록 [구현 명세 v1.0](./03-franchise-training-implementation.md)의 콘텐츠/이수 경계를 지킨다.

서비스는 **브랜드 운영 교육**과 **법정 의무 가능성이 있는 안전·개인정보 교육**을 구분한다. 가맹점 장비 사용법을 교육했다고 산업안전보건법상 교육시간·내용 요건을 자동 충족하는 것은 아니다. 산업안전보건 및 물질안전보건자료(MSDS) 교육 대상은 실제 사업장·근로자·작업·제품에 따라 확인해야 한다.

주 사용자는 본사 교육관리자, 가맹점주/점장, 현장 직원, 안전·법무 담당자다. 장비 수리·전기·고압·가스·보일러 등 위험 작업은 교육 앱이 일반 직원에게 임의로 수행법을 안내하지 않고, 제조사 또는 적격 정비업체에 이관한다.

## 2. MVP 기능

- 역할·지점·장비 모델·세제 SKU에 따른 짧은 교육 모듈 배정
- 최신 한국어 제조사 운영 매뉴얼·세제 SDS 링크/파일, 문서 언어·버전·해시·검토일 관리
- 장비 시동/정지, 안전 정지·연락, 세제 라벨/SDS·보호구·누출/접촉 대응 등 핵심 안내
- 콘텐츠 버전별 퀴즈, 이해 확인, 필요 시 현장 실습 확인자·일시 기록
- 신규 배정·미이수·재교육·개정 콘텐츠 확인 및 관리자 내보내기
- 오프라인 열람과 문서 갱신 시 새 버전 알림

정부기관 보고, 법정 교육 인정 판정, 유료 LMS, 얼굴 영상·위치 추적은 초기 제품에서 약속하지 않는다. 법정 교육 후보로 표시할 때도 안전/법무 검토자가 적용 대상·시간·실시방법을 확인한 뒤 설정한다.

## 3. 데이터·업무 흐름

콘텐츠에는 장비 모델/제품 SKU, 언어·지역, 원문 출처, 문서 발행/검토/시행일, 교육 유형, 승인자, 위험 범위, 대체 버전을 저장한다. 이수 기록은 지점·내부 학습자 ID·역할, 코스 버전, 배정/시작/완료 시각, 퀴즈 결과·시도, 현장 실습 확인을 포함한다. IP·위치·얼굴 영상 등 목적에 필요하지 않은 정보는 수집하지 않는다.

본사가 매뉴얼·교육 버전을 승인 → 가맹점주가 대상 직원·제품·장비를 확인 → 콘텐츠와 실습을 배정 → 직원이 학습·확인 → 점장이 현장 실습을 승인 → 본사가 지점별 완료 현황과 개정 영향 확인 순서다. 퇴사·지점 이전·계약 종료의 계정 회수와 이수기록 보유기간은 목적과 법적 근거를 검토해 정한다.

## 4. 안전·법률 확인 사항

- 산업안전보건법상 정기·채용·작업변경·특별교육의 대상과 범위는 사업장/근로자/실제 작업별로 검토한다.
- MSDS 교육은 대상 물질 취급자와 작업 배치, 새로운 대상물질 도입, 위험정보 변경 상황에 맞춰 관리한다. 세제가 있다고 모든 사람에게 동일한 법정 교육이 자동 적용되는 것은 아니다.
- 개인정보를 처리하는 취급자 교육과 브랜드 운영 교육도 구별한다. 교육 이력의 식별 가능성·보유기간·본사 접근 권한을 최소화한다.
- 글로벌 제조사 SDS/매뉴얼이 한국 판매 SKU 및 최신 국문판과 일치하는지 확인하고 버전을 고정한다.
- 법정 이수시간·기록 보존기간과 특정 매장/근로자 적용 여부는 안전·노무 전문가 검토 없이 확정하지 않는다.

## 5. 성공 지표·검증 질문

지표 후보: 신규 직원 첫 주 지정 교육 완료율, 콘텐츠 개정 후 새 버전 확인률, 현장 실습 누락, 세제/SKU 변경 시 SDS 확인률, 장비 오사용 문의, 반복 장애 신고, 관리자 자료 갱신 시간이다. 사고 감소 인과는 비교자료가 확보되기 전까지 가설이다.

- 각 매장의 근로자 수·실제 업종·고용형태·작업별 안전교육 대상은 누구인가?
- 사용 세제의 제조사·정확한 제품명/SKU·한국어 SDS와 위험성 변경 통지자는?
- 모델별 최신 국문 장비 매뉴얼과 직원 작업/AS 기사 이관 경계는?
- 브랜드 교육·산업안전보건 교육·MSDS 교육 기록을 별도로 남길 필요는?
- 본사가 개인별 퀴즈 점수를 봐야 하는가, 매장별 이수 현황이면 충분한가?
- 기존 교육기관/LMS/서명 기록을 연동하거나 대체할 때 필요한 증빙은?
- 오프라인/개인기기/언어 지원과 현장 실습 확인 책임자는?
