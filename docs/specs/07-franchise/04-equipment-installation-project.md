# [기획서] 세차장 장비 설치 프로젝트 관리

> **카테고리**: 07 본사·가맹점 서비스 (C급 · 확장)  
> **앱 ID**: `app-equipment-installation-project`  
> **문서 상태**: 법령·프로젝트관리 제품 조사 기반 — 계약/공종/부지별 적용 확인 필요  
> **목적**: 부지 검토부터 계약·설계·공사·장비 설치·시운전·인수인계까지 담당자, 승인, 일정과 증빙을 추적한다.

## 1. 사용자와 범위

본사 프로젝트 관리자, 가맹점주/발주자, 설계·시공사와 전문 공종, 장비 제조사·설치 기사, 인허가·안전·회계 담당자가 참여한다. 앱은 일정·문서·결정 이력 관리 도구이며 지자체 인허가, 설계 검토, 법정 검사, 안전관리 책임을 대신하지 않는다.

건설·건축·폐수·전기·산업안전 의무는 부지, 설비, 공사 실질, 계약과 당사자의 역할에 따라 달라진다. 모든 장비 설치에 같은 허가가 필요하다고 전제하지 않고, 프로젝트 초기 해당 여부·담당 전문가·관할 기관 확인을 게이트로 둔다.

## 2. 프로젝트 단계와 통과 게이트

| 단계 | 주요 업무 | 다음 단계 전 확인 |
| --- | --- | --- |
| 1. 부지·기회 검토 | 주소/권리, 건물 용도, 물·전력·배수·차량 진입, 관계기관 사전 질의 | 입지와 유틸리티·인허가 위험 기록 |
| 2. 범위·계약 | 세차 방식·베이·사양, 공종 분할, 일정·납기·대금·변경·하자·인수조건 | 범위·책임·예산·기준 일정 승인 |
| 3. 설계·인허가 | 배치·기초·배관·폐수·전력·제어·안전 도면, 해당 허가·신고 검토 | 승인 도면 버전과 착공 조건 확정 |
| 4. 제작·조달 | 장비 BOM·시리얼·납기·대체품·공장검사·출하 확인 | 기반공사 준비와 주요 납기 확인 |
| 5. 공사·설치 | 토목/건축·전기·배관·폐수·장비 설치, 현장 안전·사진·이슈 | 유틸리티 연결, 설치 점검, 미결함 목록 |
| 6. 시험·시운전 | 해당 검사 여부·결과, 누수·압력·운영 프로그램·결제·안전정지 시험 | 합격 기준 승인 및 안전 결함 해소 |
| 7. 인수·종결 | 준공/검사 문서, 도면, 시리얼·보증·매뉴얼·SDS·교육, 펀치리스트·최종 지급 | 인수 서명, 문서 수령, 잔여 책임·기한 확인 |

## 3. MVP 기능·역할

- 단계 템플릿, 담당자·기한·선후행 관계·기준 일정과 실제 일정
- 도면/문서 버전·제출·승인·반려·유효일·접근 권한
- 장비 BOM, 모델/시리얼, 발주·제작·납기·대체품 승인
- 해당 허가/검사 여부, 담당자, 신청·승인일과 증빙 링크
- 현장 일지, 사진, 정보요청(RFI), 위험/이슈, 변경요청
- 변경요청의 원인·요청자·도면버전·비용/납기/허가/안전 영향·승인자·결정 이력
- 시험 조건·결과·미달 조치·펀치리스트와 최종 인수 확인

본사 PM은 기준선과 변경을 관리하고, 발주자는 부지·운영 요구와 비용/도면 변경을 승인한다. 시공·전문업체는 작업·검사 증빙과 일정 변경을 제출하고, OEM/설치기사는 장비 시리얼·설치·시운전·매뉴얼/보증을 제공한다. 승인 전 변경을 구두 지시만으로 발주하지 않도록 서면 결정을 남긴다. 지연의 귀책은 자동 판정하지 않고 당사자 확인 자료를 기록한다.

## 4. 데이터·접근 통제

핵심 데이터는 `project`, `site`, `contract`, `work_package`, `task`, `dependency`, `drawing_revision`, `equipment_bom`, `permit_check`, `inspection`, `rfi`, `change_request`, `risk_issue`, `site_diary`, `commissioning_test`, `punch_item`, `handover_document`, `payment_milestone`다. 일정·비용·문서 승인은 프로젝트 구성원·역할에 따라 분리하고, 조회·수정·다운로드·승인 기록을 보존한다. 법정 원본 보관 시스템을 대체한다고 홍보하지 않고 초기에는 문서 링크·버전·접근권한·체크리스트로 시작한다.

## 5. 지표·검증 질문

지표 후보: 단계 통과일 편차, 준공/가동 목표일 지연일, 승인 전 변경 건수, 문서/RFI 대기시간, 장비 납기 준수, 시운전 1차 통과율, 인수 미결함 수, 인수 문서 완비율, 준공 후 초기 장애, 일정 최신화율이다. 데이터 정의·기준선 확보 전 성과 약속은 하지 않는다.

- 실제 계약 당사자와 발주/대금/공사 관리 책임은 누구인가? 단일 도급인가, 공종별 분리 계약인가?
- 신축·증설·기존 용도변경별로 필요한 관할 확인과 검사 담당은?
- 본사, 점주, 설계/시공사, OEM의 단계별 승인권과 변경·하자·지급 기준은?
- 설계에서 유틸리티·배수·폐수·동절기·소음 등 조건을 누가 확정하는가?
- 시운전 합격 수치, 시험 시나리오, 결제/원격관제 연동과 비상 정지 기준을 누가 승인하는가?
- 현장 담당자 기기·통신·사진 보유·접근 정책과 기존 문서/PM 도구는?
