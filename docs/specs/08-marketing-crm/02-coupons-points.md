# [기획서] 세차장 쿠폰·포인트

> **카테고리**: 08 마케팅·고객관리 (C급 · 확장)  
> **앱 ID**: `app-coupons-points`  
> **문서 상태**: 소비자·전자금융 자료 조사 기반 — 포인트/쿠폰/충전형 잔액의 법적 분류와 회계 검토 필요  
> **목적**: 세차장별 쿠폰·추천·생일 혜택과 충전 보너스를 투명하게 발행·사용·취소하고 잔액 원장을 관리한다.

## 1. 상품 유형과 설계 원칙

“쿠폰”, “무료 포인트”, “충전 잔액”, “선불 이용권”은 명칭만으로 환불·만료·규제 기준이 같다고 가정하지 않는다. 고객이 대가를 지급했는지, 발행 범위와 가맹점, 양도·환급 가능성, 제3자 사용 여부 등 실제 거래 구조를 기준으로 상품별 법률·회계 검토가 선행되어야 한다. 세차장 한 곳에서만 쓰는 자체 이용 잔액인지, 여러 지점·사업자에서 쓰는 선불 지급수단인지도 확인한다.

MVP는 고객에게 부담·약관이 복잡해지는 충전형 선불 잔액을 만들기 전, 무료 방문 쿠폰·추천 혜택·생일 혜택부터 검증한다. 충전 보너스가 포함된 유상 잔액은 별도 상품 유형으로 관리하며, 법률 검토와 환불·정산 정책이 확정되기 전에는 판매하지 않는다.

## 3. 원장·정산·환불 설계

쿠폰 상태를 덮어쓰지 않고 `발행`, `유상 충전`, `무상 보너스`, `적립`, `사용`, `취소`, `환불`, `만료/소멸`, `수동 조정` 이벤트를 불변 원장으로 기록한다. 잔액이 포함된 상품은 유상·무상 버킷, 발행자, 결제 참조, 사용 배분 규칙, 환급 상태를 분리한다. 이벤트에는 고유 멱등 키, 원거래, 수행자·사유·승인자, 잔액 전후를 남긴다. 소비자 잔액의 신탁/예치 등 법적 선불충전금 보호 의무가 미확인 구조에 자동 적용된다고 표현하지 않는다.

환불 순서, 일부 사용 잔액 환급, 쿠폰 취소 복원, 유효기간 연장, 매장 폐업·서비스 불가 처리, 무료 보너스 처리와 포인트 소멸 규칙은 상품과 관련 법·계약 검토 후 명시한다. 고객이 지불한 충전금과 사업자가 무상 제공한 보너스 포인트를 한 금액으로 합쳐 표시하거나 동일한 환불/만료로 처리하지 않는다. 유상 충전은 서비스 제공 전 수취액의 회계 처리를 전문가가 검토하며, 모두 즉시 매출이라고 가정하지 않는다.

데이터 모델: `promotion`, `coupon_definition`, `coupon_issuance`, `wallet_account`, `ledger_entry`, `redemption`, `refund`, `store_scope`, `funding_source`, `consent_reference`, `approval`, `reconciliation_batch`. 모든 항목에 생성/사용 매장, 발행자, 재원, 캠페인·약관 버전, 원거래 키와 감사 로그를 기록한다.

## 4. 소비자 고지·법률·개인정보

- 금액 충전, 정액권, 특정 매장 이용권, 무상 포인트, 쿠폰의 유형과 발행/사용 범위를 법률·회계 담당자가 검토한다. 전자금융거래법 적용/등록 여부는 발행잔액·연간 총발행액 외의 법정 요건 및 예외를 포함해 전문가가 판단한다.
- 유상 잔액 환급 약정과 전액 환급 사유, 소비자분쟁해결기준상 상품권 분류·유효기간·환급 기준을 약관과 실제 상품에 맞춰 확인한다. 소비자분쟁해결기준의 수치가 모든 매장 포인트/무료쿠폰에 자동 적용된다고 가정하지 않는다.
- 구매 전 총 가격·보너스·사용 가능 매장/서비스·유효기간·양도/환불/취소·이용 제한·폐업 시 처리 조건을 분명히 표시한다.
- 추천/생일 혜택 발송은 CRM의 광고 수신 동의·수신거부 상태와 연동한다. 쿠폰 발행 자체가 광고 동의를 의미하지 않는다.
- 연락처는 혜택 전달에 필요한 경우에만 사용하고, 고객 간 추천관계/생일은 최소 데이터로 관리한다. 차량번호·결제카드 원문은 수집하지 않는다.

## 5. 지표·위험·검증 질문

지표 후보는 발행/사용/미사용율, 만료 전 사용, 재방문, 프로모션별 증분 방문(대조군 가능 시), 매장별 사용/정산 차이, 부정·중복 사용, 취소/환불 분쟁, 고객 불만, 본사·점포별 부담 비용이다. 매출 증대 효과는 대조군과 기간을 둔 검증 전까지 가설로만 둔다.

- 고객에게 판매하려는 상품은 자체 매장 서비스권, 충전형 잔액, 다지점 선불수단, 무료 쿠폰 중 무엇인가?
- 사용 지점/법인/제휴 가맹점의 범위와 양도·현금 환불·일부 잔액 환불 방식은?
- 유상 충전액과 보너스 포인트를 어떤 순서로 차감하고 각 이벤트를 회계에 어떻게 반영하는가?
- 만료·휴업·폐업·서비스 변경 시 고객 처리와 점포/본사 부담 주체는?
- POS/키오스크·모바일 쿠폰 검증·취소·오프라인 장애 대응은 어떤 방식인가?
- 전자금융거래법상 선불전자지급수단/등록 요건, 상품권·전자상거래·표시 의무가 실제 구조에 적용되는가?
- 본사·매장·제휴처 중 발행자·판매자·환불 책임자·개인정보 처리자는 누구인가?
- 혜택 발송을 위한 채널별 광고 동의와 수신거부를 어떻게 증명·동기화할 것인가?
