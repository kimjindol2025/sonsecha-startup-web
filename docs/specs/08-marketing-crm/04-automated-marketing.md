# [기획서] 세차장 자동 마케팅

> **카테고리**: 08 마케팅·고객관리 (C급 · 확장)  
> **앱 ID**: `app-automated-marketing`  
> **문서 상태**: 조사 초안 — 가상 날씨/CRM 미발송 데모는 [구현 명세 v1.0](./04-automated-marketing-implementation.md)을 따른다. 실API/발송 미연결.  
> **목적**: 매장 운영 조건, 지역 날씨, 고객의 방문 간격에 맞춘 캠페인을 제안하고, 동의·승인·빈도 제한을 통과한 메시지만 발송한다.

## 1. 제품 원칙

> Codex는 실제 동의·날씨·고객 데이터를 연결하거나 자동 발송하지 않는다. 미리보기/승인 데모의 모든 규칙은 [구현 명세 v1.0](./04-automated-marketing-implementation.md)에 정했다.

자동화는 조건에 맞는 캠페인 초안을 만드는 데서 시작한다. 초기 버전은 날씨 데이터와 고객 세그먼트를 이용해 대상을 미리 보여주고 담당자가 승인한 뒤 발송한다. 기상 예보가 오래됐거나 불확실하고, 수신 동의·수신거부 상태가 확인되지 않거나 매장이 운영 중단 상태면 발송하지 않는다.

날씨는 지점 위치에 대응하는 지역 격자를 사용한다. 고객 주소·실시간 위치·차량번호는 수집하지 않는다. 날씨 데이터의 예보 오차와 지역·계절별 반응 차이 때문에 비·황사 캠페인의 효과를 당연시하지 않는다.

## 2. MVP 사용자와 업무 흐름

| 역할 | 주요 작업 |
| --- | --- |
| 본사 마케팅 담당 | 캠페인 규칙·템플릿·예산·채널 조건 작성, 지점 범위 설정 |
| 캠페인 승인자/준법 담당 | 메시지 분류·광고 고지·동의·수신 제한 확인 후 승인 |
| 지점 관리자 | 영업시간·세차 가능 상태·재고·비용 분담 확인 |
| CRM/발송 운영자 | 기상/API 연결, 수신 억제목록·발송 모니터링, 장애 중단 |
| 고객 | 동의한 채널로 캠페인 수신, 쉬운 수신거부/설정 변경 |

1. 담당자가 지점/캠페인 유형(비 예보, 황사·미세먼지, 장기 미방문, 쿠폰)을 선택한다.
2. 시스템은 최신 기상 자료와 매장 운영 가능 여부, 고객 세그먼트, 채널별 동의·수신거부를 확인한다.
3. 예상 대상 수, 제외 사유, 예보 출처·발행시각, 발송 문구, 쿠폰·예산을 미리 보여준다.
4. 권한자가 승인하고 발송을 예약한다. 예약된 발송 직전 동의·거부 목록과 매장 운영 상태를 다시 검사한다.
5. 취소/킬스위치, 실패·중복·발송량 경보와 캠페인 결과를 기록한다.

## 3. 캠페인 규칙과 발송 안전장치

- 규칙에 지점 ID, 기상 조건, 예보 시각/유효기간, 매장 운영 상태, 고객 세그먼트, 채널, 메시지 분류, 쿨다운, 일일 상한, 예산, 승인자를 포함한다.
- API 장애·낡은 예보·격자 매핑 오류 시 fail-closed로 중단하고 수동 검토만 허용한다.
- 한 고객/지점에 여러 조건이 겹치면 중복 제거, 고객당 최소 발송 간격과 캠페인별 상한을 적용한다. 상한·쿨다운 값은 파일럿에서 정한다.
- 발송 직전 수신동의·수신거부·연락처 유효성·야간 제한을 다시 확인한다. 철회된 수신자를 suppression list에서 즉시 제외한다.
- 광고성 문구, 발신자 정보, 쉬운 무료 수신거부를 채널별 승인 템플릿으로 관리한다. 알림톡 등 서비스 안내용 메시지 채널에 할인/이벤트 광고를 섞지 않는다.
- 대상 샘플 테스트, 승인 로그, 멱등 키, 예약 취소, 대량 발송 킬스위치, 재시도 중복 방지와 결과 대사를 제공한다.
- 고객 세그먼트·개별 할인 여부가 중대한 완전 자동 결정을 구성하는지, 결정 기준 공개/설명·사람 개입 요구가 적용되는지는 설계·법률 검토 후 확정한다.

## 4. 데이터·개인정보·채널 설계

핵심 데이터는 `store`, `weather_location`, `forecast_snapshot`, `campaign_rule`, `segment`, `consent_state`, `suppression`, `message_template`, `approval`, `send_batch`, `delivery_event`, `coupon_event`, `experiment_assignment`다. 고객은 내부 랜덤 ID, 동의한 채널의 최소 연락처, 방문 간격/횟수 등 필요한 세그먼트 값만 사용한다. 개인 주소·GPS·차량번호는 자동 마케팅 기준에 포함하지 않는다.

날씨 스냅샷에는 지점 격자/지역 코드, 관측·예보 종류, 발행/수신시각, 데이터 출처·API 버전을 기록하되 원자료 저장·재배포는 API 라이선스와 이용약관을 확인한다. 발송·수신거부 로그는 캠페인 규칙/동의 문구 버전·발신자·전송 시각·처리 결과를 연결한다. 본사, 지점, CRM SaaS, 메시지 사업자의 처리자/수탁자 역할과 재위탁/국외 이전은 데이터 흐름·계약 검토 후 정한다.

채널별 사전 동의, 발신자 표시, 광고 식별, 야간 전송, 수신거부와 재확인 요구를 분리 관리한다. 광고성 정보와 계약 이행에 필요한 서비스 알림을 같은 캠페인 타입으로 취급하지 않는다. 기존 거래 고객 예외를 적용하려면 직접 거래·직접 수집 연락처·동종 상품/서비스·허용 기간 등 요건을 법무가 확인해야 하므로 기본값은 명시적 채널별 광고 수신 동의다.

## 5. 실험·지표·검증 질문

날씨 자체가 세차 수요를 바꾸는 효과와 캠페인 효과를 구별하기 위해 무작위 홀드아웃 또는 단계별 지점 출시를 사용한다. KPI 후보는 증분 방문율/재방문율, 쿠폰 사용, 할인 후 공헌이익, 캠페인당 발송비, 오발송·중복률, 동의 누락 발송(목표 0), 거부 반영 지연, 실패율, 불만/스팸 신고다. 클릭률만으로 성공을 판단하지 않는다.

- 발송 채널별 동의 문구·수집 시점·수신거부 증빙과 발신 사업자는 무엇인가?
- 본사/점포 중 누가 개인정보처리자, 수탁자, 제3자 제공자이며 고객 민원·삭제요청 책임자는 누구인가?
- 점포 격자와 API 예보 갱신주기·호출량·상업적 이용/저장/재배포 조건은 무엇인가?
- 비·황사 예보 뒤 실제 세차 수요와 캠페인 전환이 지역·계절별로 어떻게 달라지는가?
- 매장별 운영시간, 장비 점검·휴업, 쿠폰 예산과 발송 비용의 승인자는 누구인가?
- 캠페인 빈도, 쿨다운, 최대 할인, 중복 쿠폰 허용범위가 고객/점포에 미치는 영향은?
- 완전 자동 발송과 승인 발송 중 운영자가 신뢰하고 법무가 허용할 범위는 무엇인가?
- 카카오/SMS/이메일/앱푸시별 최신 템플릿·광고 표기·야간/수신거부 정책은?

| 단계 | 실행 내용 | 완료 기준 |
| --- | --- | --- |
| 0. 데이터·동의 점검 | 채널·CRM 동의·지점 운영정보·기상 API 권한/약관 확인 | 개인정보/광고 검토와 데이터 흐름 승인 |
| 1. 수동 승인 캠페인 | 날씨·방문 간격으로 초안, 예상 대상·제외 이유 미리보기 | 매장 운영 적합성과 오발송 방지 확인 |
| 2. 통제된 실험 | 홀드아웃·발송 상한·쿨다운·캠페인별 비용/결과 측정 | 증분 방문·마진·민원 기준 판단 |
| 3. 제한 자동화 | 승인된 규칙만 자동 예약, 발송 직전 상태 재검사 | kill switch·철회 반영·장애 중단 확인 |
