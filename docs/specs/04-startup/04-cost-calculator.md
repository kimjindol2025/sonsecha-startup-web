# [기획서] 세차장 창업비용 계산기 (Carwash Capex Estimator)

> **카테고리**: 04 창업 서비스 (B급 · 수익화)  
> **앱 ID**: `app-startup-cost-calc`  
> **목적**: 토지 임차 보증금, 토목·기초 패드 타설, 건축 패널, 세차 장비 본체, 전기 증설, 폐수처리기, 키오스크까지 항목별 총 창업 투자비용(Capex)을 산출

---

## 1. 서비스 개요 및 타깃
- **대상 사용자**: 세차장 창업 예산 계획 수립자, 자기자본 및 대출 규모 산정이 필요한 투자자
- **핵심 가치**:
  - 흔히 누락되어 추가 공사비 폭탄을 맞는 **"숨은 비용"**(한전 불입금, 정화조 인입, 소방 인허가비) 사전 반영
  - 2베이 / 3베이 / 4베이 규격별 표준 견적 템플릿 제공
  - 자기자본 대비 시설대출(리스/렌탈) 활용 시 실제 현금 소요액 계산

---

## 2. 항목별 표준 창업비용 구성표 (3베이 노터치 기준)

| 대분류 | 세부 내역 | 예상 비용 범위 (VAT 별도) | 비고 |
| :--- | :--- | :---: | :--- |
| **토지 및 인허가** | 보증금, 설계/토목 감리비, 인허가 면허세 | 5,000만 ~ 1억 5,000만 원 | 입지에 따라 상이 |
| **토목 및 기초 공사**| 흙파기, 잡석 다짐, 철근 콘크리트 패드(250mm) 타설 | 4,000만 ~ 6,000만 원 | 바닥 동파 배관 매립 포함 |
| **건축 및 캐노피** | 샌드위치 판넬 부스, 드라잉존 캐노피 차양막 | 5,000만 ~ 8,000만 원 | 3베이 + 6드라잉존 기준 |
| **세차 장비 (주설비)**| 노터치 자동세차기 3대 (본체 + 펌프 + 건조기) | 1억 8,000만 ~ 2억 4,000만 원| 대당 6,000만 ~ 8,000만 원 |
| **환경 및 수처리** | 생물학적/물리화학적 폐수처리기 (10~15톤/일) | 2,500만 ~ 3,500만 원 | 유수분리조 및 활성탄 포함 |
| **전기 및 설비** | 한전 불입금(100kW), 수전 설비, 온수 보일러 | 2,500만 ~ 4,000만 원 | 인입 거리에 따라 변동 |
| **결제 및 부대설비** | 무인 결제 키오스크 3대, CCTV, 진공청소기 6대 | 2,000만 ~ 3,000만 원 | RF 발급기 포함 |
| **합계 (Total Capex)**| **총 창업 소요 예산** | **약 3억 9,000만 ~ 6억 3,500만 원** | 보증금 규모에 따라 상이 |

## 3. 데이터 스키마

```typescript
export interface StartupCapexEstimate {
  targetBayCount: number;       // 2, 3, 4
  landType: 'own' | 'lease';    // 자가 소유 vs 토지 임대
  landLeaseDeposit: number;
  
  civilConstructionCost: number;// 토목/바닥 콘크리트
  buildingCanopyCost: number;   // 건축/캐노피
  equipmentCost: number;        // 노터치 세차기 본체
  wastewaterFacilityCost: number;// 폐수처리시설
  electricalPlumbingCost: number;// 전기 한전 불입금 및 배관
  kioskAndPeripheralCost: number;// 키오스크 및 청소기
  contingencyBudget: number;    // 예비비 (총액의 5%)
  
  totalInvestment: number;      // 총 투자비
  recommendedEquity: number;    // 권장 자기자본 (최소 40% 이상)
  loanFeasibilityAmount: number;// 장비 리스/시설대출 가능액
}
```
