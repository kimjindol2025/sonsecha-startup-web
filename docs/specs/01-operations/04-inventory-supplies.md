# [기획서] 소모품·재고 관리 앱 (Supplies & Inventory Management App)

> **카테고리**: 01 운영·관리 (A급 · 현장 필수)  
> **앱 ID**: `app-ops-inventory`  
> **목적**: 세제(프리워시/스노우폼), 왁스/발수코팅제, 공용 타월, 키오스크 영수증 롤 등 필수 소모품의 잔여량을 추적하고 안전재고 미달 시 자동 발주

---

## 1. 서비스 개요 및 타깃
- **대상 사용자**: 세차장 점주, 케미컬 납품 대리점, 물품 발주 담당자
- **핵심 가치**:
  - 주말 세차 피크타임 중 약품 품절로 인한 영업 중단 사태 원천 차단
  - 일일 세차 대수 비례 소진 속도 추정으로 정확한 발주 타이밍 제시
  - 복수 공급업체별 단가 및 납품 리드타임(주문 후 도착 일수) 관리

## 3. 데이터 구조 및 발주 로직

```typescript
export interface InventoryItem {
  sku: string;                  // "CHEM-PREWASH-20L"
  name: string;                 // "파워 프리워시 20L"
  category: 'chemical' | 'towel' | 'kiosk_paper' | 'filter' | 'winter_material';
  currentStock: number;         // 현재 수량
  minimumSafetyStock: number;   // 최소 안전재고 (이 수치 이하 시 경보)
  unit: string;                 // "통", "롤", "장", "박스"
  unitPrice: number;            // 매입 단가 (원)
  supplierName: string;         // 공급처
  supplierPhone: string;
  leadTimeDays: number;         // 배송 소요 일수
  averageDailyUsage: number;    // 최근 7일간 일평균 소진량
}
```

---

## 4. 자동 발주 제안 알고리즘
$$\text{잔여 가동 일수} = \frac{\text{현재고}}{\text{일평균 소진량}}$$
- **발주 제안 조건**: $\text{잔여 가동 일수} \le \text{배송 소요 일수(leadTimeDays)} + 2\text{일}$
- **원클릭 발주 기능**: 공급사 담당자 번호로 [사업장명, 품목, 수량, 배송주소]가 담긴 발주 문자/카카오톡 템플릿 자동 생성
