# 작업 지시

목표: 기존 20단계 도구를 보존하며 기획안의 탐색형 입구와 읽기 화면을 GitHub Pages에 배포한다.

1. 기존 메인을 guide.html로 보존하고 Vite 입력 추가.
2. 독자 브랜드 메인, 주제·단계 검색과 정적 실무 가이드 작성.
3. Pages의 서버 접수 한계 표시, 운영 상담으로 연결. 기존 로컬 기록 유지.
4. 빌드·실제 브라우저·정적 링크와 저장 회귀 검증.
5. 검증 기록을 남기고 변경만 master에 반영, Pages 배포와 공개 결과 확인.

금지: 저장 키 변경, 기록 삭제, 기존 앱 삭제, 신한 자산 복제, 가짜 순위·후기·시공 실적, 운영 서버 변경.
