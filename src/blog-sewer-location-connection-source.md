# BIGWASH 블로그 원고 — 오수관·우수관 위치와 공공하수 연결

## 01 · 오수관·우수관 위치와 공공하수 연결 가능 여부, 현장 전에 확인하세요

세차장 폐수 배수계획에서 가장 먼저 해야 할 일은 “가까운 관로에 연결”하는 것이 아닙니다. 해당 주소가 공공하수도 처리구역인지, 대지와 건물의 배수계통이 어떻게 구성되어 있는지, 세차폐수를 어떤 처리 절차로 공공하수도에 유입할 수 있는지 확인해야 합니다.

### 오수관과 우수관을 구분합니다

오수관은 생활하수나 사업장 배수처럼 오염 가능성이 있는 물을 처리시설로 보내는 계통이고, 우수관은 빗물을 배제하는 계통입니다. 분류식 지역에서는 두 계통이 별도로 설치될 수 있으며, 합류식 지역에서는 하나의 관로에 함께 흐를 수 있습니다.

세차폐수의 배출 경로는 세차 방식, 폐수배출시설 해당 여부, 처리시설, 공공하수도 관리청의 기준에 따라 확인해야 합니다. 우수관에 세차폐수나 처리되지 않은 오염수를 연결하는 것은 허용된다고 볼 수 없으므로, 기존 건물의 배관이 어느 계통인지 확인하기 전 임의로 연결하지 마세요.

### 관로 위치는 여러 자료를 맞춰 봅니다

1. 관할 하수도 부서에 주소·지번을 제시해 처리구역과 공공관로 위치 문의
2. 배수설비 준공도면과 기존 건물 배관도 확인
3. 대지 경계·도로·맨홀·측구·우수받이 현장 사진 기록
4. 국가하수도정보시스템 등 공개 자료에서 처리구역을 참고
5. 기존 배관의 오접 여부와 실제 유출 방향을 설계자와 확인

공개 지도는 참고자료일 수 있으므로 관로의 정확한 위치·관경·심도·접속 가능 여부를 지도만으로 확정하지 않습니다. 최종 연결 지점과 공사 방법은 관할 공공하수도관리청의 답변과 현장조사를 기준으로 정리하세요.

### 공공하수도 연결 가능성은 다섯 가지를 봅니다

1. **처리구역:** 주소가 공공하수도 처리구역에 포함되는지
2. **인접 관로:** 대지 앞 도로 또는 인접 구간에 연결 가능한 공공관로가 있는지
3. **고도와 배수 방향:** 건물 바닥·배수구와 관로의 높이 차이로 자연 유하가 가능한지
4. **수용과 기준:** 추가 배수량·수질·유입 조건을 관리청이 수용할 수 있는지
5. **공사 가능성:** 도로굴착·점용·사유지 통과·복구와 비용 부담이 가능한지

고도 차이 때문에 자연 유하가 어려우면 펌프나 별도 배수설비를 설계할 수 있지만, 설치 가능 여부와 유지관리 책임은 건축사·설비설계자·하수도 부서에 확인해야 합니다. 펌프를 설치한다고 연결이 자동 승인되는 것은 아닙니다.

### 처리구역 밖이거나 관로가 없을 때

공공하수도 처리구역 밖이거나 연결할 공공관로가 없다면 개인하수처리시설, 위탁처리, 다른 배출 경로 등 대안을 검토해야 할 수 있습니다. 어떤 대안이 가능한지는 세차 방식·폐수량·수질·토지 조건·관할 기준에 따라 달라지며, 개인하수처리시설을 설치하면 된다고 자동 결론 내릴 수 없습니다.

이 경우 환경 부서와 하수도 부서에 같은 자료를 제출하고, 폐수배출시설 신고·허가와 하수 처리·배출 절차가 어떻게 연결되는지 서면으로 확인하세요.

### 기관에 문의할 때 준비할 자료

1. 정확한 도로명·지번·건물 동·층·호
2. 건축물대장과 기존 평면도·배수설비 도면
3. 세차 방식·베이 수·예상 세차 대수·일 최대 폐수량
4. 세제·약품 사용과 폐수처리시설 계획
5. 오수·우수·세차장 바닥 배수의 분리 계획
6. 연결 예정 위치·배관 경로·고도와 도로굴착 범위
7. 토지 사용 권원과 건물주 협의 내용

기관에는 “이 주소에서 세차폐수를 어떤 처리 후 어떤 공공관로로 유입할 수 있는지”, “배수설비 설치신고·사용 관련 절차가 무엇인지”, “도로굴착·점용과 원인자부담금이 필요한지”를 구체적으로 묻습니다.

### 확인부터 공사까지의 흐름

1. 주소와 기존 배관 자료로 처리구역·관로 위치 사전 문의
2. 현장조사로 오수·우수 계통, 배수 방향, 고도 확인
3. 폐수처리·배수설비·도로굴착 계획을 도면에 반영
4. 관할 기관에 필요한 신고·허가·협의와 비용 확인
5. 승인·협의된 내용대로 시공하고 연결·복구·검사 기록 보관
6. 사용 개시와 운영기록 등 후속 의무를 기관에 확인

배수설비 설치신고, 하수도 사용 관련 절차, 폐수배출시설 신고·허가는 대상과 지역에 따라 서로 다른 절차일 수 있습니다. 하나의 접수로 모두 끝난다고 가정하지 말고 각각의 담당 기관과 제출서류를 확인하세요.

### BIGWASH에서는 이렇게 기록합니다

허가 확인 페이지에서 오수관·우수관 위치, 공공하수도 연결 가능 여부, 처리구역, 고도·접속 지점, 확인일·출처 URL·근거 메모를 후보지별로 저장할 수 있습니다. 아직 관로가 확인되지 않았으면 미판정으로 남기고, 도면·현장사진·기관 답변을 관리자 상담 자료로 연결하세요.

**확인 포인트:** “세차폐수는 무조건 오수관에 연결”이라는 문장만으로 공사하지 않습니다. 폐수 처리, 공공하수도 유입 조건, 배수설비, 도로굴착·복구를 함께 확인하고 우수관 오접을 예방해야 합니다.
