# BIGWASH 블로그 원고 — 건물 동·층·호와 면적

## 01 · 건물 동·층·호와 실제 사용할 면적, 계약 전에 맞춰 보세요

세차장 후보지를 상담하거나 용도변경·폐수·하수도·공사 계획을 준비할 때 주소와 면적을 대략 적으면 서류 사이에 불일치가 생길 수 있습니다. 건축물대장, 등기사항증명서, 임대차계약서, 현장 표시가 같은 공간을 가리키는지 먼저 맞춰야 합니다.

### 집합건물은 동·층·호를 정확히 선택합니다

정부24 또는 세움터에서 건축물대장을 열람·발급할 때 집합건축물은 건물 전체 대장과 전유부 대장을 구분해 확인합니다. 아파트·오피스텔·상가복합건물처럼 여러 호가 있는 경우 동·층·호를 잘못 선택하면 다른 전유부의 면적과 용도가 표시될 수 있습니다.

단독 건물이나 일반건축물은 대장에 표시된 건물명·주용도·층별 현황을 확인하고, 임대차계약서의 호칭과 실제 출입구 표시가 일치하는지 비교합니다. 주소 표기가 도로명과 지번으로 섞여 있다면 같은 필지를 가리키는지 함께 확인하세요.

### 건축물대장에서 확인할 항목

1. 대장 구분: 일반건축물인지 집합건축물인지
2. 건물명·동·층·호와 전유부 위치
3. 현재 용도와 층별 용도
4. 전유면적 또는 전용면적
5. 공용면적·주차장·부속시설 표시
6. 건축면적·연면적·대지면적
7. 위반건축물 표시와 변동사항
8. 발급일과 발급 기관

건축물대장은 공부상 현황을 보여주는 자료입니다. 실제 공간의 벽·출입구·창고·캐노피·배관 위치가 대장이나 현황도와 일치하는지는 현장에서 별도로 확인해야 합니다.

### 면적 이름을 섞어 쓰지 마세요

전유면적은 집합건물에서 특정 구분소유자가 독립적으로 사용하는 부분의 면적을 말하고, 공용면적은 복도·계단 등 공동으로 사용하는 부분을 말합니다. 일반건축물의 건축면적은 건물이 대지를 덮는 수평투영면적이고, 연면적은 각 층 바닥면적의 합계입니다.

세차장 계획에서 실제 영업·시공 대상이 되는 공간은 임대차계약 범위, 건축물대장·도면의 표시, 현장 측량 결과를 함께 봐야 합니다. 폐수량·주차·소방·용도변경·도로 진입 검토에 쓰는 면적이 항상 동일하다고 볼 수 없으므로, 신청서 항목별로 해당 기관과 전문가에게 어떤 면적을 기재할지 확인하세요.

### 서류와 현장을 비교하는 방법

1. 임대차계약서의 주소·동·층·호·면적을 표시합니다.
2. 건축물대장 전유부와 층별 현황에서 같은 공간을 찾습니다.
3. 등기사항증명서의 소재지·전유부분 표시와 소유자를 비교합니다.
4. 기존 평면도에서 임대 범위·출입구·기둥·배관 위치를 확인합니다.
5. 현장 사진과 실측 메모로 실제 사용 범위를 기록합니다.
6. 불일치가 있으면 임대인·관리사무소·관할 건축과에 원인을 문의합니다.

대장보다 실제 면적이 넓거나 도면에 없는 공간이 있으면 무단증축·무단용도변경 가능성을 확인해야 합니다. 반대로 현장에 보이지 않는 공용부나 구조부가 계약 면적에 포함된 경우도 있으므로, 차이를 곧바로 위반으로 단정하지 말고 자료별 면적의 의미를 구분하세요.

### 신청서마다 면적 기준을 확인합니다

용도변경, 폐수배출시설, 배수설비, 도로점용, 사업자등록 등에 제출하는 면적은 신청 목적과 서식에 따라 요구하는 범위가 다를 수 있습니다. “모든 신청은 전용면적만 기입한다”고 정하지 말고 다음을 기록하세요.

1. 신청기관과 신청서 이름
2. 요구하는 면적 항목과 단위
3. 공부상 면적과 실제 사용면적
4. 공용부·주차장·외부 작업공간 포함 여부
5. 면적 확인일·출처·담당자 답변

특히 세차 베이, 장비실, 폐수처리시설, 사무실, 대기·회차 공간을 하나의 “전체 평수”로만 적으면 설계와 기관 협의가 어려워집니다. 공간별 면적표와 평면도를 함께 준비하는 것이 좋습니다.

### 주소·면적 불일치가 발견되면

임대차계약서와 건축물대장이 다르면 계약 상대방에게 정정 또는 확인을 요청합니다. 등기사항증명서와 계약 상대방의 관계, 공동소유·대리계약 여부도 확인합니다. 현장과 공부가 다르면 관할 건축과나 건축사에게 용도·면적·위반 여부를 문의하고, 원인을 확인하기 전에는 용도변경이나 시설공사를 확정하지 않는 편이 안전합니다.

### BIGWASH에서는 이렇게 기록합니다

허가 확인 페이지에서 정확한 건물 동·층·호와 실제 사용할 면적을 후보지별로 저장하고, 체크 상태·판정·확인일·출처 URL·근거 메모를 함께 남길 수 있습니다. 건축물대장과 현장 사진의 차이, 임대인에게 다시 물어볼 내용, 기관 상담이 필요한 면적 항목을 분리해 관리하세요.

**확인 포인트:** 건축물대장의 면적 하나를 모든 신청서에 그대로 복사하지 않습니다. 전유부·전용면적·공용면적·건축면적·연면적과 실제 사용 범위를 구분하고, 신청기관의 서식 기준을 확인하세요.
